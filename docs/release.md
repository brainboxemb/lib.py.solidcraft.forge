# Release boundary

Forge NEW does not publish a package release during bootstrap or the early example-migration slices.

The migrated package currently carries version `0.15.0` only to represent the source baseline from historical Forge. That is not a NEW release claim.

Before the first NEW release:
- package/API parity must be demonstrated;
- representative CAD graph migration must be accepted;
- release validation must be explicitly migrated or redesigned on top of the new owner boundaries;
- stable source/build evidence must be defined independently of Pages;
- version/tag/release automation must be qualified on NEW itself.

Do not copy the historical release workflow wholesale merely to preserve file layout.
