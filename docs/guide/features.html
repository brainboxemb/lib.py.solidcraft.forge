A feature changes an existing body

A native feature is different from subtracting arbitrary CSG geometry. SCPF can retain named sketches and operations in SolidCraft history. For exact results, supported body types and selection constraints matter.

Holes

from scpf import Box, Hole, Depth, Faces

plate = Box(100, 60, 10)
hole = Hole(d=8, depth=Depth.THROUGH_ALL)
plate = plate + hole.on(plate, face=Faces.TOP)

A Hole is a native hole feature: adding it to the shape means adding the operation that removes material. Faces.TOP selects its entry face. Simple feature placement uses on(); assembly attachment uses explicit anchors.

Native feature patterns

Pattern an already-applied native feature when the copies should remain one editable SolidCraft history operation. Rectangular and circular patterns share the same source-feature rules: pass the same Forge Shape object that was applied to the body. Forge resolves that object to its native history feature; callers never manage SolidCraft timeline-name strings. Direct native Hole-family and primitive features are supported alongside the existing Sketch.extrude() path, and a direct count Parameter remains editable in the saved design.

from scpf import Anchor, Axis, Box, Hole

plate = Box(100, 80, 6, anchor=Anchor.BOTTOM)
bolt_hole = Hole(
    d=8,
    direction=(0, 0, -1),
).at(30, 0, 6)
plate = plate + bolt_hole

bolt_circle = plate.circular_pattern(
    bolt_hole,
    count=6,
    axis=Axis.Z,
)

circular_pattern() omits angle by default so SolidCraft uses its native 360-degree full-circle behaviour. Supply a fixed degree value or direct Parameter for a partial arc. origin=(x, y, z) moves a fixed axis; a fixed non-zero XYZ vector can be used instead of Axis.X/Y/Z. Construction-axis and geometry-axis selectors are not yet exposed by Forge.

grid = plate.rectangular_pattern(
    bolt_hole,
    count=4,
    spacing=20,
    direction=Axis.X,
    count2=3,
    spacing2=18,
    direction2=Axis.Y,
)

rectangular_pattern() and circular_pattern() both emit one native feature-pattern command rather than expanding independent copies in Python.

Fillets and chamfers

from scpf import FRONT, LEFT, Box, Edges

body = Box(80, 50, 15)
rounded = body.fillet(3, edges=Edges.VERTICAL)
bevelled = body.chamfer(3, edges=Edges.VERTICAL)
one_edge = body.chamfer(3, edges=FRONT + LEFT)

fillet() and chamfer() use the same edge-selection forms. Use Edges.VERTICAL for all vertical edges of a supported rectangular body, a two-direction selector such as FRONT + LEFT for one Box edge, Edges.from_profile(...) or Edges.from_vertices(...) for named Polygon2D geometry, or explicit XYZ pick coordinates. Both methods default to Edges.VERTICAL. A topological edge cannot always be inferred reliably from a visual camera position.

Shells

from scpf import Box, Faces
case = Box(80, 50, 30).shell(2, open=Faces.TOP)

Faces.TOP chooses the face to open and is also the same surface-selection vocabulary used by feature.on(...). Anchor is reserved for explicit component attachment in assemblies. See the source and regression tests for supported feature chains.

Feature placement without hard-coded global offsets

from scpf import X, Y, Boss, Anchor

boss = Boss(d=7, h=12, hole_d=2.5).attach(
    case, parent=Anchor.INNER_BOTTOM,
    offset=(X.MIN + 10, Y.MAX - 10),
)

X.MIN and Y.MAX refer to the parent bounds and are not rotation-axis constants. Anchoring support currently focuses on rectangular bases and a documented set of faces. Do not assume every curved or lofted surface supports it.
