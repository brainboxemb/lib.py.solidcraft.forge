Forge can attach a native SolidCraft technical drawing to a completed design. Drawing intent is presentation state: keep it out of reusable component definitions and add it only when the part or assembly you want to document is complete.

Add a drawing to one component

@component
class SamplePlate:
    def build(self):
        return Box(80, 50, 8, anchor=Anchor.BOTTOM)

part = SamplePlate().with_drawing(name="Sample Plate Drawing")

with_drawing() uses SolidCraft's native iso-a4-part template by default and sets its first sheet to landscape. SolidCraft owns the paper, title block, standard front/top/right/isometric view layout and fitted scale. Forge binds the native drawing, component, occurrence, source, sheet and view identities returned by SolidCraft rather than predicting browser ids.

A4 by default, A3 when you ask for it

part.with_drawing(
    name="Large assembly detail",
    template="iso-a3-part",
)

A4 landscape is the normal part-drawing default. Select A3 explicitly when the design needs more sheet area; the chosen native paper size is preserved and the sheet remains landscape. Forge does not silently switch an A3 request back to A4.

Document one component from an assembly

assembly = left + right
assembly = assembly.with_drawing(
    left,
    name="Left bracket",
)

The selected occurrence must already belong to the completed Assembly. Projected views inherit the selected native occurrence subtree. Drawing intent does not alter normal occurrence placement or duplicate the reusable component definition.

Drawing intent versus published artifacts

Forge stores the native drawing in model.sc and declares the drawing artifact. The SCPF builder reopens that saved design and uses SolidCraft's native drawing.export command twice: a vector PDF for publication and a 144 dpi PNG of the replay-bound sheet for static visual evidence. Forge model code does not embed repository or build-root paths.

build/<scope>/models/sample-plate-drawing/scpf/
  model.sc
  drawings/
    Sample-Plate-Drawing.pdf
    Sample-Plate-Drawing.png

Pages loads only the static PNG preview and exposes explicit Open PDF / Download PDF actions. It does not embed the PDF viewer on page load and copies neither generated artifact into gh-pages. See the Sample Plate Drawing example for the complete source, generated SolidCraft sequence, native model and drawing PDF.

Current drawing scope

The patch-qualified drawing slice covers native landscape part sheets, standard views, vector PDF publication and a native static sheet preview. Dimensions, notes, title-block authoring overrides, explicit view placement, balloons and parts lists remain separate future authoring capabilities. They will be evaluated against a real downstream Wall Hook drawing after this patch rather than being hidden as example-specific behavior.
