Forge can attach a native SolidCraft technical drawing to a completed design. Drawing intent is presentation state: keep it out of reusable component definitions and add it only when the part or assembly you want to document is complete.

Add a drawing to one component

@component
class SamplePlate:
    def build(self):
        return Box(80, 50, 8, anchor=Anchor.BOTTOM)

part = SamplePlate().with_drawing(name="Sample Plate Drawing")

with_drawing() uses SolidCraft's native iso-a4-part template by default. SolidCraft owns the paper sheet, standard front/top/right/isometric view layout and fitted scale. Forge binds the native drawing, component, occurrence, source, sheet and view identities returned by SolidCraft rather than predicting browser ids.

A4 by default, A3 when you ask for it

part.with_drawing(
    name="Large assembly detail",
    template="iso-a3-part",
)

A4 is the normal part-drawing default. Select A3 explicitly when the design needs more sheet area; Forge does not silently change paper size.

Document one component from an assembly

assembly = left + right
assembly = assembly.with_drawing(
    left,
    name="Left bracket",
)

The selected occurrence must already belong to the completed Assembly. Projected views inherit the selected native occurrence subtree. Drawing intent does not alter normal occurrence placement or duplicate the reusable component definition.

Drawing intent versus published artifacts

Forge stores the native drawing in model.sc and declares the drawing artifact. The SCPF builder reopens that saved design and uses SolidCraft's native drawing.export command to produce a vector PDF below the implementation's drawings/ directory. Forge model code does not embed repository or build-root paths.

build/<scope>/models/sample-plate-drawing/scpf/
  model.sc
  drawings/
    Sample-Plate-Drawing.pdf

Pages links that durable build evidence; it does not copy the PDF into gh-pages. See the Sample Plate Drawing example for the complete source, generated SolidCraft sequence, native model and drawing PDF.

Current drawing scope

The released drawing slice covers native standard part views and PDF publication. Dimensions, balloons, parts lists and broader annotation authoring remain separate future capabilities rather than hidden behavior in this first drawing API.
