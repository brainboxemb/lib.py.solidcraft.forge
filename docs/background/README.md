# Forge background documentation

This directory preserves historical and narrow supporting material that is
useful for understanding how the current Forge design evolved, but is not a
primary current contract.

- `changes/` — numbered implementation/change records;
- `design/` — audits, architecture deep-dives, remediation and qualification records;
- `ci-baseline-2026-11-20.md` — verified CI timing/coverage baseline and parked findings before durable build/Pages migration;
- `microcad-inspiration.md` — external design inspiration;
- `documentation-architecture.md` — earlier documentation-architecture record;
- `generated-output.md` — generated-output/publication migration record;
- `reference-libraries.md` — pinned external comparison-library working notes.

Current contracts live one level up in `api.md`, `design.md`,
`development.md`, `plan.md`, `requirements.md` and `release.md`.
