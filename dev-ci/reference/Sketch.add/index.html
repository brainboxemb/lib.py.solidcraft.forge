Sketch.add()

Add and place a supported 2D profile in this Sketch.

Current Python signature

Sketch.add(self, profile, *, anchor=None, offset=(0, 0))

When to use it

Add a profile explicitly or apply a deliberate sketch-local offset. Dimension-defined profiles default to semantic CENTER. Polygon2D, Text2D and native Slot profiles keep their authored coordinates.

Current limits

Explicit Anchor.CENTER is supported for Circle2D, Rectangle2D and RoundedRectangle2D. Polygon2D, Text2D and native Slot profiles define their own sketch-local coordinates; leave anchor=None for those profile types.
