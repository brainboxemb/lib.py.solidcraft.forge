Compiler and runner API

Lower-level entry points for compiling Shapes or trusted model source files.

Worked usage in the guide → · Cross-object API design rules →

compile_model

compile_model(shape: scpf.core.Shape, name: str) -> dict

Compile one Shape tree to a native SolidCraft command document.

When to use it

Lower-level tooling already has a final Shape object and needs the JSON command plan without executing a model source file.

Parameters

ArgumentMeaning
shapeFinal Shape tree to compile.
nameModel/body name used for generated SolidCraft commands. It must be a valid identifier.

Example

document = compile_model(Box(80, 50, 12), "Panel")

Current limits

The final value must be a Shape. Normal user workflows usually call the scpf runner/CLI instead.

run_script

run_script(path: str | pathlib.Path) -> dict

Execute a trusted SCPF model source file and return its command document.

When to use it

Programmatic tooling needs the same model-loading/root-selection and compilation behaviour as the SCPF CLI.

Parameters

ArgumentMeaning
pathPath to the trusted Python model source file.

Example

document = run_script("models/panel/scpf/model.py")

Current limits

The source is executed as trusted Python. A file must either end in an explicit root model call or define exactly one unambiguous public model class with build().
