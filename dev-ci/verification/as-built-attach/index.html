As-built rigid relationship preserves pose

What this example makes

The Base remains centred at Z=0: [-20,-15,-5]..[20,15,5]. The 30x10 Marker remains quarter-turned to a 10x30 footprint at [45,5,11]..[55,35,19] after the native as-built joint is created.

Forge code

This is the complete Forge source used for this example.

"""Qualification: as-built attachment preserves an existing child pose."""


class Base:
    WIDTH = 40.0
    DEPTH = 30.0
    HEIGHT = 10.0

    def build(self):
        return Box(self.WIDTH, self.DEPTH, self.HEIGHT)


class Marker:
    LENGTH = 30.0
    WIDTH = 10.0
    HEIGHT = 8.0

    def build(self):
        return Box(self.LENGTH, self.WIDTH, self.HEIGHT)


class AsBuiltAttach:
    def build(self):
        base = Base()
        marker = Marker(
            placement=Placement(
                x=50,
                y=20,
                z=15,
                rotation=((0, 0, 1), 90),
            )
        ).attach(base, as_built=True)
        return base + marker

"""CadQuery assembly reference preserving an already authored marker pose.

The Assembly Location expresses the occurrence pose independently of any
constraint. Forge additionally qualifies the persisted SolidCraft as-built
relationship.
"""

import cadquery as cq

base = cq.Solid.makeBox(40, 30, 10, cq.Vector(-20, -15, -5))
marker = cq.Solid.makeBox(30, 10, 8, cq.Vector(-15, -5, -4))
marker_pose = (
    cq.Location((50, 20, 15))
    * cq.Location(cq.Vector(0, 0, 0), cq.Vector(0, 0, 1), 90)
)

model = cq.Assembly()
model.add(base, name="base")
model.add(marker, name="marker", loc=marker_pose)

        with Locations(Rot(0, 0, 90)):
            Box(30, 10, 8, align=center)

How Forge builds it in SolidCraft

Forge binds the real Base and Marker occurrence IDs returned by native component creation, applies the complete Marker pose through replay-bound occurrence.move, then emits joint.as_built(type='rigid') using those bound IDs. No predicted Component:N occurrence name and no anchor-origin solve is used.

Reference documentation

  • SolidCraft — The native as-built rigid relationship constrains two already-positioned occurrences without solving a new mating position.
  • PythonSCAD — Independent geometry preserves the translated and rotated Marker pose without using Forge.
  • pyBOSL2 — Independent bottom-anchored geometry verifies the same world-space Marker envelope.
  • CadQuery — Assembly Location independently represents the authored occurrence pose.
  • build123d — Independent placed and rotated box geometry verifies the same visible baseline.
