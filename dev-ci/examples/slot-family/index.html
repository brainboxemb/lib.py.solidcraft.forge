Native sketch Slot family

All five SolidCraft Slot construction methods live in one explicit sketch

One plate sketch contains five closed Slot profiles created with the five native Slot construction methods and removed with one through cut.

Model stages

  1. Create the native Box plate
  2. Create five Slot profiles in one named sketch
  3. Cut the complete Slot family through the plate once

Goal

Qualify all five SolidCraft 0.42 Slot construction methods as direct SCPF sketch profiles rather than approximating them with rounded rectangles or hand-built curves.

Forge API

SlotCenterToCenter2D(...); SlotOverall2D(...); SlotCenterPoint2D(...); SlotArcThreePoint2D(...); SlotArcCenter2D(...) inside one explicit Sketch

Forge model

One 160 x 120 x 5 mm plate with five separate closed Slot profiles in one named sketch, removed with one through-all cut.

How Forge builds it in SolidCraft

Each public constructor emits exactly its matching sketch.slot.* command; the sketch is finished once and one native cut extrusion removes all five profiles.

SolidCraft result

SolidCraft saves one plate, one Slot family sketch containing five closed profiles and one error-free cut extrusion. The native timeline must not contain sketch.rectangle.rounded as a substitute for Slot construction.

Saved-design test

No saved-design mutation is required; this case isolates the five native sketch construction methods and their saved feature history.

Python source

"""Qualification fixture for all five native SolidCraft Slot creators."""


class SlotFamily:
    width = 160.0
    depth = 120.0
    thickness = 5.0

    SLOT_WIDTH = 8.0

    def build(self):
        body = Box(
            self.width,
            self.depth,
            self.thickness,
            anchor=Anchor.BOTTOM,
        )

        with Sketch(name="Slot family", on=body) as slots:
            SlotCenterToCenter2D((-60, -35), (-40, -35), self.SLOT_WIDTH)
            SlotOverall2D((-10, -35), (20, -35), self.SLOT_WIDTH)
            SlotCenterPoint2D((55, -35), (65, -35), self.SLOT_WIDTH)
            SlotArcThreePoint2D((-50, 25), (-35, 38), (-20, 25), self.SLOT_WIDTH)
            SlotArcCenter2D((40, 25), (52, 25), self.SLOT_WIDTH, sweep=120)

        return body - slots.extrude(Depth.THROUGH_ALL)
