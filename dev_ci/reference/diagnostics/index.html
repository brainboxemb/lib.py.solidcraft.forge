Errors and warnings

Public diagnostics for invalid model intent and lost symbolic parameter dependencies.

Cross-object API design rules →

ModelError

Report unsupported or invalid CAD model intent.

When to use it

Catch Forge compilation/model validation failures separately from normal Python argument errors when integrating the lower-level compiler API.

Current limits

User model code normally fixes the underlying model instead of handling this exception as a recoverable geometry result.

ModelParameterWarning

Warn that an editable model parameter lost a native CAD dependency.

When to use it

Tooling wants to detect parameters that became concrete Python values or are only partly associative in the generated SolidCraft model.

Current limits

This is a warning category, not an exception. The preferred fix is to preserve the symbolic relationship or mark an intentional build-time input with a leading underscore.
