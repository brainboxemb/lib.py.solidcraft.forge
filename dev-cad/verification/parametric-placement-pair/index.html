Symmetric parametric occurrence Placement

What this example makes

With spacing=80 mm the two 20 mm blocks are centred at X=-40 and X=+40.

Forge code

This is the complete Forge source used for this example.

"""Qualification: symmetric parametric occurrence Placement without joints."""


class Block:
    def build(self):
        return Box(20, 20, 10)


class ParametricPlacementPair:
    spacing = 80.0

    def build(self):
        left = Block(
            placement=Placement(x=-half(self.spacing))
        )
        right = left.copy(
            placement=Placement(x=half(self.spacing))
        )
        return left + right

How Forge builds it in SolidCraft

Forge publishes spacing, creates one Block definition, binds both real occurrence IDs, and emits two occurrence.move expressions using -(spacing / 2) and spacing / 2. No predicted occurrence name and no placement joint is used.
