    Cheatsheet

    Quick lookup for the public SCPF authoring API.

    Model classes

    class Example: … build(self)

    Write a Python model. No main() or show() is required.

    class SimpleBox:
    def build(self):
        return Box(40, 30, 10)

    Related model

    Model parameters

    Numeric model fields become named SolidCraft parameters.

    length = 40.0
Box(self.length, 30, 10)

    Related model

    Shapes and sketches

    Box(length, width, height, *, anchor=CENTER)

    Native Box centred on XYZ by default; choose anchor=BOTTOM for a bottom-face datum at Z=0.

    Box(40, 30, 10)

    Related model

    Rectangle2D(width, depth)

    Planar XY profile authored inside a Sketch.

    with Sketch(plane='XY') as sketch:
    Rectangle2D(100, 60)

    Related model

    Circle2D(d=…)

    A round 2D profile authored inside a Sketch.

    with Sketch(plane='XY') as sketch:
    Circle2D(d=8)

    Polygon2D(points, plane=…)

    A closed profile on XY, XZ or YZ.

    Polygon2D([(0,0), (40,0), (0,30)], plane='XZ')

    Cylinder(d=…, h=…, axis=…, anchor=CENTER)

    Native cylinder centred by default; choose an axial anchor such as BOTTOM or LEFT when that end should define the datum.

    Cylinder(d=24, h=14, axis=Axis.X, anchor=LEFT)

    Sphere(radius, *, anchor=CENTER)

    Native sphere centred by default; cardinal anchors select tangent datums.

    Sphere(12, anchor=LEFT)

    Sheet metal

    Sketch.sheet_metal(…)

    Create a new native flat sheet body from one closed Sketch and define its shared material rule.

    sheet = sketch.sheet_metal(thickness=2, bend_radius=2, k_factor=0.5)

    Shape.fold(…)

    Fold existing sheet material along one straight line; material values come from the active sheet rule.

    sheet = sheet.fold(line=((20,-20,0),(20,20,0)), angle=90, fixed=(-30,0,0))

    Shape.flange(…)

    Grow a native flange from one or more fixed existing-sheet edge picks.

    sheet = sheet.flange(edges=[(40,0,2)], height=20, angle=90)

    Shape.contour_flange(…)

    Create a new native sheet body from a finished connected open Sketch chain.

    sheet = contour.contour_flange(distance=50, thickness=2.5, bend_radius=2.5)

    Shape.hem(…)

    Fold an existing sheet edge back while inheriting the active material rule.

    sheet = sheet.hem(edges=[(40,0,2)], length=12, gap=4)

    Shape.path_flange(…)

    Add a native flange to an existing edge using a finished line-only open Sketch path.

    sheet = sheet.path_flange(edge=(40,0,2), path=path, radius=3)

    Shape.perforate(…)

    Apply a native whole-sheet manufacturing perforation field without repeated solid hole cuts.

    sheet = sheet.perforate(diameter=5, pitch=10, margin=5, pattern='square')

    Related model

    Features and placement

    sketch.extrude(distance)

    Extrude an explicitly authored Sketch into editable native solid history.

    with Sketch(plane='XY') as sketch:
    Rectangle2D(80, 50)
plate = sketch.extrude(8)

    Related model

    sketch.extrude(…, profiles=[…])

    Extrude or cut only the closed Sketch regions selected by fixed sketch-local points.

    cut = sketch.extrude(Depth.THROUGH_ALL, profiles=[(-30, 0), (30, 0)], exact_regions=True)

    Sketch.rectangular_pattern(…)

    Repeat a profile or earlier Sketch result as a native rectangular sketch pattern.

    row = sketch.rectangular_pattern(seed, count=4, spacing=25, direction=Axis.X)

    Sketch.mirror(…)

    Mirror a profile, pattern result or earlier mirror result over the Sketch X or Y axis.

    sketch.mirror(row, axis=Axis.Y)

    Hole(d=…, depth=…)

    A native hole. THROUGH_ALL follows the target body.

    Hole(d=8, depth=Depth.THROUGH_ALL)

    Related model

    shape.rectangular_pattern(…)

    Repeat an already-applied native feature in one or two linear directions.

    plate.rectangular_pattern(hole, count=4, spacing=20, direction=Axis.X)

    shape.circular_pattern(…)

    Repeat an already-applied native feature around a fixed axis.

    plate.circular_pattern(hole, count=6, axis=Axis.Z)

    shape.at(target, anchor=…, child=…)

    Place a direct CSG shape anchor on another shape anchor; CENTER-to-CENTER is supported first.

    Cylinder(d=8, h=50, axis=Axis.X).at(body)

    Related model

    shape.on(target, face=…)

    Place a feature on a selected face of another shape.

    Hole(d=8, depth=Depth.THROUGH_ALL).on(plate, face=Faces.TOP)

    Related model

    TOP + LEFT / BOTTOM + RIGHT

    Combine cardinal directions to identify one edge of an axis-aligned rectangular solid.

    body.fillet(2, edges=[BOTTOM + LEFT, BOTTOM + RIGHT])

    Box(…).at(…, anchor=…)

    Place a native Box by a face, edge or corner anchor without creating a Sketch.

    Box(80, 50, 12).at(0, 0, 0, anchor=FRONT + BOTTOM)

    shape.fillet(…)

    Round selected edges of a feature-based body.

    body.fillet(2, edges=Edges.VERTICAL)

    shape.chamfer(…)

    Bevel selected edges using the same edge selectors as fillet.

    body.chamfer(2, edges=Edges.VERTICAL)

    shape.shell(…)

    Create an open-sided shell (supported feature trees only).

    Box(80, 50, 30).shell(2, open=Faces.TOP)

    a + b / a - b / a & b

    Join, cut or intersect supported shapes; operation support depends on the shape types.

    body + Hole(d=8).at(0, 0, 10)

    Reusable components

    copy(placement=Placement(…))

    Create another occurrence of the same component definition at a declared pose.

    second = first.copy(placement=Placement(x=40))

    Related model

    model.attach(…)

    Fix one reusable component to another through explicit attachment references.

    right = Block().attach(left, parent=Anchor.RIGHT, child=Anchor.LEFT)

    Related model

    attach(offset=(u, v))

    Keep an in-plane attachment offset associative; parameter expressions become native planar-joint values.

    part.attach(base, parent=Anchor.FRONT_TOP_LEFT, child=mount, offset=(0, -wall + 12))

    Related model

    assembly.with_exploded_view(…)

    Store a native automatic or explicit exploded presentation without changing normal occurrence placements.

    assembly.with_exploded_view('Service', scale=1.25).show_exploded('Service')

    Related model

    assembly.show_assembled()

    Return presentation to the normal assembled occurrence placements.

    assembly.show_assembled()

    Related model

    assembly.with_anchor(…) / anchor(…)

    Expose a semantic attachment datum owned by an assembly without adding application-specific anchors to a generic component.

    frame = (left + right).with_anchor("front_top_left", left, ref)
parent = frame.anchor("front_top_left")

    Related model

    corner anchors

    Use one of the eight rectangular corner references when attaching components.

    marker = Marker().attach(base, parent=Anchor.FRONT_TOP_RIGHT, child=Anchor.BACK_TOP_RIGHT)

    Related model

    AnchorFrame

    Define an oriented local attachment frame. Return it from anchors() when the datum belongs to the reusable component, or pass it directly to attach() when it belongs only to the assembly.

    mount = AnchorFrame(origin=(0,0,-12), z=(0,1,0), x=(0,0,-1))
part.attach(base, parent=Anchor.FRONT_TOP_LEFT, child=mount)

    AnchorTopology

    Keep a named or assembly-local attachment reference on a planar-face edge or one of its endpoints so SolidCraft can follow changing geometry.

    def anchors(self):
    return {"mount": AnchorTopology(edge=(0,10,5), on=(0,10,10), corner=(0,0,5))}

    Placement(rotation=(axis, degrees))

    Give a component occurrence one absolute axis-angle orientation.

    second = first.copy(placement=Placement(x=40, rotation=(Z, 180)))

    Compile and inspect

    python -m scpf … –out

    Compile a model to SolidCraft command JSON; no SolidCraft app needed.

    python -m scpf examples/simple-box/scpf/model.py --out output/box.json

    Related model

    python -m scpf replay …

    Send existing command JSON to an open SolidCraft session; does not recompile.

    python -m scpf replay output/box.json

    python -m scpf … –connect

    Execute a model in an open SolidCraft GUI document.

    python -m scpf examples/simple-box/scpf/model.py --connect
