Native XZ extrusion face-boundary selection

Both broad extrusion faces resolve to native perimeter edges

Verified scpf 40 × 30 mm XZ profile; 15 mm symmetric Y extrusion; 1.5 mm face-perimeter chamfer

What this verifies

An XZ Polygon2D profile extruded symmetrically along Y chamfers both broad end-face perimeters through Edges.from_faces(Faces.FRONT, Faces.BACK). This is the topology pattern required by the Wall Hook consumer.

scpf/model.py
"""Native two-face XZ extrusion boundary selection qualification for #148."""


class TopologyFaceBoundaryXz:
    def build(self):
        with Sketch(name="Hook profile", plane="XZ") as sketch:
            Polygon2D(
                [(-20, 0), (20, 0), (20, 30), (-20, 30)],
                plane="XZ",
                world=True,
            )
        body = sketch.extrude(15, sym=True)
        return body.chamfer(
            1.5,
            edges=Edges.from_faces(Faces.FRONT, Faces.BACK),
        )

Model stages

  1. Sketch the closed XZ profile
  2. Extrude it symmetrically along Y
  3. Resolve the FRONT and BACK planar faces through model.faces
  4. Resolve and combine both native edge boundaries through model.edges
  5. Chamfer the returned native edge references
