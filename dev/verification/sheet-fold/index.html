Verified scpf 80 × 40 × 2 mm sheet; R2 bend, K=0.5, 90° fold, Ø6 hole

What this model makes

An 80 × 40 mm flat sheet blank with one through hole and one 90 degree native fold using a shared sheet rule. The bend line is a native Sketch line whose endpoints depend on the editable depth parameter, so changing depth after saving extends the fold line and rebuilds the sheet.

scpf/model.py
"""Native sheet-metal fold fixture used by qualification #305."""


class SheetFold:
    width = 80.0
    depth = 40.0
    thickness = 2.0
    bend_radius = 2.0
    k_factor = 0.5
    fold_angle = 90.0
    hole_diameter = 6.0

    def build(self):
        with Sketch(name="Blank", plane="XY") as blank:
            Rectangle2D(self.width, self.depth)

        sheet = blank.sheet_metal(
            thickness=self.thickness,
            bend_radius=self.bend_radius,
            k_factor=self.k_factor,
            rule_name="SheetFold Rule",
        )

        sheet = sheet + Hole(
            d=self.hole_diameter,
            direction=(0, 0, -1),
        ).at(-20, 0, self.thickness)

        with Sketch(name="Fold line", plane="XY") as fold_sketch:
            fold_line = fold_sketch.line(
                start=(20, -(self.depth / 2)),
                end=(20, self.depth / 2),
            )

        return sheet.fold(
            line=fold_line,
            angle=self.fold_angle,
            fixed=(-30, 0, 0),
        )

cadquery/model.py
"""CadQuery geometry reference for the qualified 90-degree sheet fold."""

from math import cos, pi, sin
import cadquery as cq

R_INNER = 2.0
THICKNESS = 2.0
R_OUTER = R_INNER + THICKNESS
X_TANGENT = 17.64380551
Z_TOP = 21.64380551
CENTER = (X_TANGENT, 4.0)
SEGMENTS = 32


def arc_points(radius, start, end, count=SEGMENTS):
    return [
        (
            CENTER[0] + radius * cos(start + (end - start) * i / count),
            CENTER[1] + radius * sin(start + (end - start) * i / count),
        )
        for i in range(count + 1)
    ]


outer = arc_points(R_OUTER, -pi / 2, 0)
inner = list(reversed(arc_points(R_INNER, -pi / 2, 0)))

profile = [
    (-40.0, 0.0),
    *outer,
    (X_TANGENT + R_OUTER, Z_TOP),
    (X_TANGENT + R_INNER, Z_TOP),
    *inner,
    (-40.0, 2.0),
]

sheet = (
    cq.Workplane("XZ")
    .polyline(profile)
    .close()
    .extrude(20, both=True)
)
hole = (
    cq.Workplane("XY")
    .center(-20, 0)
    .circle(3)
    .extrude(4, both=True)
)
result = sheet.cut(hole)

model = cq.Assembly()
model.add(result, name="sheet_fold")

build123d/model.py
"""build123d 0.12 geometry reference for the qualified 90-degree sheet fold.

build123d's make_brake_formed helper is not used here because the pinned 0.12
implementation fails to solidify this small R2 / 2 mm fixture. The reference
instead builds the exact folded XZ section independently and extrudes it across
the 40 mm width.
"""

from math import cos, pi, sin

from build123d import (
    Align,
    BuildPart,
    BuildSketch,
    Cylinder,
    Locations,
    Mode,
    Plane,
    Polygon,
    extrude,
)

R_INNER = 2.0
THICKNESS = 2.0
R_OUTER = R_INNER + THICKNESS
X_TANGENT = 17.64380551
Z_TOP = 21.64380551
CENTER = (X_TANGENT, 4.0)
SEGMENTS = 32


def arc_points(radius, start, end, count=SEGMENTS):
    return [
        (
            CENTER[0] + radius * cos(start + (end - start) * i / count),
            CENTER[1] + radius * sin(start + (end - start) * i / count),
        )
        for i in range(count + 1)
    ]


outer = arc_points(R_OUTER, -pi / 2, 0)
inner = list(reversed(arc_points(R_INNER, -pi / 2, 0)))
profile = [
    (-40.0, 0.0),
    *outer,
    (X_TANGENT + R_OUTER, Z_TOP),
    (X_TANGENT + R_INNER, Z_TOP),
    *inner,
    (-40.0, 2.0),
]

with BuildPart() as model:
    with BuildSketch(Plane.XZ):
        Polygon(*profile)
    extrude(amount=20, both=True)

    with Locations((-20, 0, -1)):
        Cylinder(
            3,
            4,
            align=(Align.CENTER, Align.CENTER, Align.MIN),
            mode=Mode.SUBTRACT,
        )

Model stages

  1. Create the parameterized flat rectangular Blank sketch
  2. Create native sheet material and cut the Ø6 hole while flat
  3. Author a separate Fold line Sketch whose endpoints follow depth
  4. Fold the sheet 90 degrees through the native Sketch/curve reference
  5. Change depth in the saved design and require the fold to rebuild cleanly

Engineering explanation

Flat sheet, through hole and 90° fold

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76. Machine verification lives in verification/solidcraft.py.

Legacy group: features

Goal

Qualify the fabrication workflow used by later bent parts: create one flat sheet blank, cut an ordinary Hole while flat, fold existing material, and recover the developed flat pattern.

Forge API

with Sketch(…): Rectangle2D(…); blank.sheet_metal(thickness=…, bend_radius=…, k_factor=…); sheet + Hole(…).at(…); sheet.fold(line=…, angle=…, fixed=…)

Forge model

One 80 x 40 mm rectangular flat blank with a shared 2 mm sheet rule, one Ø6 through hole in the fixed flat, and one 90 degree fold along the Y direction near the right side.

How Forge builds it in SolidCraft

Forge emits one sheet.manage_rules, one Blank sketch, one sheet.flange(type=‘base’), one native solid.hole and one native sheet.fold. No solid.extrude or fused-solid bend approximation is used.

SolidCraft result

SolidCraft 0.42 keeps one connected sheet-metal body with the Ø6 hole on the fixed flat, one native Fold feature and a flat pattern that recovers the original rectangular blank and cutout.

Saved-design test

No saved-design mutation is required in this first sheet-metal qualification. unit, integration and native geometry checks prove the shared rule, native feature history and formed geometry; a post-build flat-pattern inspection proves recoverability of the developed blank.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: false

The formed bounding box does not prove sheet thickness, the Ø6 cutout or that the upright region came from a native bend. Volume and native sheet history/flat-pattern evidence are required.

Reference notes

  • build123d — The pinned build123d 0.12.0 reference uses make_brake_formed for an independent final-geometry comparison. Its newer BuildSheet/bend API is design input only and is not silently substituted into the pinned reference runtime.
  • CadQuery — Independent final geometry is built from flat and bent solid envelopes; CadQuery does not provide the same native sheet-history contract.
  • PythonSCAD — Constructive geometry independently represents the formed envelope and through hole; native sheet rules/history remain SolidCraft-only evidence.
  • pyBOSL2 — Constructive geometry independently represents the formed envelope and through hole; native sheet rules/history remain SolidCraft-only evidence.
