TOP Sketch on circular body

A face-attached sketch resolves the largest +Z face of round geometry

Verified scpf Ø100 × 10 mm disc; Ø44 × 16 mm hub

What this model makes

A circular base extrusion receives a second explicit Sketch on its TOP face and joins a smaller circular hub without rectangular-body metadata.

scpf/model.py
"""Native qualification: TOP-attached Sketch on a circular extrusion."""


class RoundTopSketch:
    def build(self):
        with Sketch(name="Disc", plane="XY") as disc:
            Circle2D(d=100)
        body = disc.extrude(10)

        with Sketch(name="Hub", on=body, parent=Anchor.TOP) as hub:
            Circle2D(d=44)

        return body + hub.extrude(16)

Model stages

  1. Sketch and extrude the circular Disc
  2. Resolve the Disc TOP face
  3. Sketch and join the smaller Hub from that face

Engineering explanation

TOP Sketch on circular body

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76. Machine verification lives in verification/solidcraft.py.

Legacy group: fundamentals

Goal

Verify that a TOP-attached explicit Sketch can select the largest +Z planar face of a circular extrusion without rectangular-body metadata.

Forge API

disc = Sketch(… Circle2D …).extrude(10); with Sketch(on=disc, parent=Anchor.TOP): Circle2D(d=44); body + hub.extrude(16)

Forge model

One Ø100 x 10 mm circular base plus one Ø44 x 16 mm hub joined from the selected top face.

How Forge builds it in SolidCraft

Forge emits the circular base extrusion, model.faces with plane_normal=[0,0,1] and max=area, then a face-attached Hub Sketch and join extrusion. No rectangular base lookup is required.

SolidCraft result

One stepped cylindrical body spans Z=0..26 mm. Disc and Hub remain two solved native Sketch/Extrude feature pairs and the Hub is attached to the actual top face of the Disc.

Saved-design test

No saved-design mutation; this fixture isolates support-face lookup on a non-rectangular feature body.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: false

The outer bounds alone do not prove the two circular radii. Volume, radial surface probes and native Sketch history are required.

Reference notes

  • SolidCraft — Native geometry proves the face-attached Hub Sketch builds on the circular Disc and stays solved.
