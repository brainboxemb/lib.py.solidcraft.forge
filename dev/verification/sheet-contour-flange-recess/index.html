scpf/model.py
"""Minimal #845 contour-flange recess replay regression fixture."""


class SheetContourFlangeRecess:
    length = 250.0

    PROFILE_WIDTH = 27.0
    PROFILE_HEIGHT = 18.0
    THICKNESS = 1.25
    OPENING = 15.0
    BEND_RADIUS = 1.25
    K_FACTOR = 0.40

    HOLE_DIAMETER = 12.5
    HOLE_OFFSET = 37.5

    def build(self):
        thickness = self.THICKNESS
        half_side = (self.PROFILE_WIDTH - thickness) / 2
        lower_z = thickness / 2
        upper_z = self.PROFILE_HEIGHT - thickness / 2
        opening_half = self.OPENING / 2

        with Sketch(name="C profile", plane="XZ") as profile:
            chain = profile.chain(start=(-opening_half, lower_z))
            chain.line_to((-half_side, lower_z))
            chain.line_to((-half_side, upper_z))
            chain.line_to((half_side, upper_z))
            chain.line_to((half_side, lower_z))
            chain.line_to((opening_half, lower_z))
            contour = chain.finish()

        rail = contour.contour_flange(
            distance=self.length,
            thickness=thickness,
            bend_radius=self.BEND_RADIUS,
            k_factor=self.K_FACTOR,
            rule_name="Contour Recess Rule",
        )

        with Sketch(
            name="Broad face recess",
            on=rail,
            parent=Anchor.TOP,
        ) as recess:
            recess.add(
                Circle2D(d=self.HOLE_DIAMETER),
                offset=(0, self.HOLE_OFFSET),
            )

        cut = recess.extrude(Depth.THROUGH_ALL)
        return rail - cut

Engineering explanation

Contour flange recess replay

Group: sheet-metal Saved-design required: false

Documentation provenance: Forge #845 live/headless contour-flange recess investigation.

Goal

Reproduce the smallest known downstream divergence around a valid recess on a native contour flange without carrying the Mounting Rail M8 assembly or repeat pattern.

Forge API

Sketch.chain(...), Shape.contour_flange(...), face-attached Sketch(..., on=..., parent=Anchor.TOP), Circle2D(...) and Sketch.extrude(Depth.THROUGH_ALL).

Forge model

The fixture uses a 250 mm long 27 × 18 × 1.25 mm C-profile with a 15 mm opening, R1.25 bend rule and K=0.40. One Ø12.5 mm circular cut is centred across the broad 27 mm back face at Y=37.5 mm.

This is the exact first-cut position from the downstream standalone rail that fails through live replay. The 1000 mm assembly variant also fails with its first cut at Y=12.5 mm.

How Forge builds it in SolidCraft

Forge authors one open XZ contour, creates one native contour-flange sheet body, resolves the broad +Z planar face through model.faces, attaches the circular Sketch to that exact face and emits one through-all cut.

The replay document therefore contains the same face-binding boundary that is present in the downstream failure.

SolidCraft result

A successful replay produces one closed native sheet-metal body with the circular recess on the broad planar face and keeps both source Sketches in native history.

Saved-design test

No parameter mutation is required for this regression. The baseline native replay itself is the qualification: SolidCraft must accept the valid recess and save the resulting native sheet body.

Geometry evidence

Geometry-rationale provenance: Forge #845 minimal downstream reproduction.

Bounds sufficient: false

Bounds alone cannot prove that the circular cut was accepted as a valid recess on the intended sheet face or that the face-binding/replay boundary behaved correctly. Native saved-design history is required.

Reference notes

  • Downstream Mounting Rail M8 — The fixture preserves the physical C-profile and first broad-face recess geometry that exposed Forge #845; no product pattern or assembly behavior is needed to reproduce the native operation.
