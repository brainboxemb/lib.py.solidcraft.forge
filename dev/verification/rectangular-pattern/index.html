Native rectangular feature pattern

One Slot cut is repeated by a two-direction native History pattern

Verified scpf 120 × 80 × 4 mm plate; 3 × 2 Slot pattern; 24 × 28 mm pitch

What this model makes

A plate receives one Slot source cut and SolidCraft repeats that existing feature in a rectangular rows-and-columns pattern.

scpf/model.py
"""Native SolidCraft rectangular feature-pattern qualification."""


class RectangularPattern:
    columns = 3
    rows = 2
    pitch = 24.0
    row_pitch = 28.0

    def build(self):
        plate = Box(120, 80, 4, anchor=Anchor.BOTTOM)
        with Sketch(name="Slot", on=plate) as slot:
            SlotCenterToCenter2D((-5, 0), (5, 0), 6)

        source_cut = slot.extrude(-4)
        plate = plate - source_cut
        return plate.rectangular_pattern(
            source_cut,
            count=self.columns,
            spacing=self.pitch,
            direction=Axis.X,
            count2=self.rows,
            spacing2=self.row_pitch,
            direction2=Axis.Y,
        )

"""PythonSCAD geometry reference for the 3 x 2 rectangular slot pattern."""

from pythonscad import *

plate = cube([120, 80, 4], center=True).up(2)

def slot_cut(x, y):
    bar = cube([10, 6, 8], center=True).translate([x, y, 2])
    left = cylinder(d=6, h=8, center=True).translate([x - 5, y, 2])
    right = cylinder(d=6, h=8, center=True).translate([x + 5, y, 2])
    return bar | left | right

cutters = None
for y in (0, 28):
    for x in (0, 24, 48):
        cutter = slot_cut(x, y)
        cutters = cutter if cutters is None else cutters | cutter

model = plate - cutters

Model stages

  1. Create the plate and source Slot sketch
  2. Cut the source Slot once
  3. Repeat the cut with one native rectangular feature pattern

Engineering explanation

Native rectangular feature pattern

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76. Machine verification lives in verification/solidcraft.py.

Legacy group: features

Saved-design required: true

Goal

Qualify a real SolidCraft rectangular History pattern over one existing cut feature, rather than Forge-expanded repeated geometry.

Forge API

source = slot.extrude(-4); body = body - source; body.rectangular_pattern(source, count=columns, spacing=pitch, direction=Axis.X, count2=rows, spacing2=row_pitch, direction2=Axis.Y)

Forge model

One 120 x 80 x 4 mm plate, one native straight Slot cut and one native 3 x 2 rectangular feature pattern.

How Forge builds it in SolidCraft

Forge emits the source Sketch/cut once, then exactly one solid.pattern.rectangular with features=[‘Slot’]; columns/rows are dimensionless native parameters and pitches remain millimetre parameters.

SolidCraft result

SolidCraft saves one plate with six slot cuts and one native rectangular pattern History feature that references the original Slot cut.

Saved-design test

Required because columns and pitch are saved native pattern parameters. Change columns from 3 to 2 and pitch from 24 to 30 mm in the saved .sc design; the pattern must rebuild to a 2 x 2 layout without rerunning Python while retaining one source Slot cut and one RectangularPatternFeature.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: false

The six slot cuts do not change the plate envelope. Volume and 3D slot-wall probes are required.

Reference notes

  • SolidCraft — Native integration through geometry checks additionally prove one saved RectangularPatternFeature. The four comparison libraries independently prove the final 3 x 2 slot geometry.
