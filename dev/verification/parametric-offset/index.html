Editable local offset at an attachment

Attachment-plane offset keeps its local coordinate meaning

Verified scpf Base 40 × 30 × 20 mm; Marker 10 mm cube; local shift 5 mm

What this verifies

A Marker is corner-attached to a Base with a symbolic local planar offset that remains editable in the saved SolidCraft relationship.

Snapshot of the saved native SolidCraft model, not an STL render.

scpf source

Complete primary source from the site branch; built revision below.

scpf/model.py
class Base:
    def build(self):
        return Box(40, 30, 20, anchor=Anchor.BOTTOM)


class Marker:
    def build(self):
        return Box(10, 10, 10, anchor=Anchor.BOTTOM)


class ParametricOffset:
    shift = 5.0

    def build(self):
        base = Base()
        marker = Marker().attach(
            base,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=Anchor.BACK_TOP_RIGHT,
            offset=(0, -self.shift),
        )
        return base + marker


ParametricOffset()

Engineering explanation

Editable local offset at an attachment

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Legacy group: associativity

Saved-design required: true

Goal

Verify the existing local (u,v) attachment-plane offset and make its coordinate semantics explicit.

Forge API

attach(…, offset=(u, v))

Forge model

Attachment stores two symbolic local planar values; these are not world X/Y/Z coordinates.

How Forge builds it in SolidCraft

The computed child seed pose retains the symbolic local offset, then the actual relationship is joint.create(type=‘planar’, values=[u,v,angle]). The seed move is not an additional joint.

SolidCraft result

The marker moves within the selected corner anchor’s local attachment plane.

Saved-design test

Change shift from 5 to 10 mm in the saved design; the marker must follow the same local axis by another 5 mm.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: true

The base and marker sizes and positions show the local offset. The saved SolidCraft model is then changed to confirm that the planar joint updates correctly.

Reference notes

  • BOSL2 — Important reference: attach() operates in the local coordinate system at the parent anchor, not blindly in world coordinates.
  • OpenSCAD — A raw translate([x,y,z]) is world/object transform syntax and therefore is not equivalent to this local joint offset.

cadquery source · pass

cadquery/model.py
"""CadQuery geometry reference for a corner marker with a planar shift.

The final Location compares the visible local-offset result. Forge separately
qualifies persisted local joint-frame mutation in SolidCraft.
"""

import cadquery as cq


shift = 5.0
base = cq.Solid.makeBox(40, 30, 20, cq.Vector(-20, -15, 0))
marker = cq.Solid.makeBox(10, 10, 10, cq.Vector(-5, -5, -5))

model = cq.Assembly()
model.add(base, name="base")
model.add(marker, name="marker", loc=cq.Location((15, -20, 20)))

from build123d import Align, Box, BuildPart, Locations

shift = 5.0

with BuildPart() as model:
    Box(40, 30, 20, align=bottom)
    with Locations((15, -15 - shift, 20)):
