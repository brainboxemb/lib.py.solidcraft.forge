Shifted-axis Revolve

One stepped offset revolve cut remains one native suppressible feature

No published build evidence scpf axis x=8 mm; axis z=3 mm; relief Ø4.5 mm; core Ø3.7 mm

What this model makes

A stepped radial profile is revolved 360 degrees around a Y-axis shifted to a parameter-driven X/Z location, then applied as one cut to a panel. A native configuration row suppresses that exact revolve feature as one unit.

scpf/model.py
"""One shifted native revolve cut is one suppressible configuration feature."""


class ShiftedAxisRevolve:
    axis_x = 8.0
    axis_z = 3.0
    relief_d = 4.5
    core_d = 3.7

    def build(self):
        panel = Box(40, 24, 20)

        with Sketch(
            name="Stepped pass through",
            plane="XY",
            offset=self.axis_z,
        ) as profile:
            Polygon2D(
                [
                    (self.axis_x, -12),
                    (self.axis_x + self.relief_d / 2, -12),
                    (self.axis_x + self.relief_d / 2, -9),
                    (self.axis_x + self.core_d / 2, -9),
                    (self.axis_x + self.core_d / 2, 9),
                    (self.axis_x + self.relief_d / 2, 9),
                    (self.axis_x + self.relief_d / 2, 12),
                    (self.axis_x, 12),
                ],
                plane="XY",
            )

        pass_through = profile.revolve(
            axis=AxisLine(
                Axis.Y,
                origin=(self.axis_x, 0, self.axis_z),
            ),
        )
        body = panel - pass_through

        return Configure(
            body,
            active="Cut",
            columns=(Suppress(pass_through),),
            rows={
                "Cut": (False,),
                "Suppressed": (True,),
            },
        )


ShiftedAxisRevolve()

Engineering explanation

This case verifies that a shifted revolve is still one native SolidCraft history feature, so configuration suppression can target the complete cut.

The panel-pin pass-through is intentionally stepped:

  • rear relief: Ø4.5 mm;
  • core: Ø3.7 mm;
  • front relief: Ø4.5 mm.

The profile is authored on an XY Sketch whose Z offset is the symbolic axis_z parameter. The revolve uses:

AxisLine(Axis.Y, origin=(self.axis_x, 0, self.axis_z))

Both the Sketch plane and revolve axis therefore follow the same native parameter at Z, while the profile and axis X position follow axis_x.

The active Cut configuration keeps the revolve feature enabled. The saved .sc is reopened and switched to Suppressed; SolidCraft suppresses the single revolve feature and the body volume increases. Switching does not branch Python and does not leave separate relief cylinders behind.

Model stages

  1. Author a parameter-driven XY profile on the axis Z plane
  2. Revolve around one typed AxisLine parallel to world Y
  3. Apply the complete stepped pass-through as one native cut feature
  4. Switch the saved configuration to suppress and restore that exact feature
