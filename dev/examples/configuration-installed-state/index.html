Free / Installed state

One flexible-fit component keeps manufacturing and mounted geometry as native configuration rows

Verified scpf Free diameter 20.4 mm; Installed diameter 20.0 mm

What this model makes

A split flexible sleeve is slightly oversized in its Free manufacturing state and compressed to its Installed working diameter after mounting. Both are rows of one native SolidCraft configuration table.

scpf/model.py
"""Qualification: one flexible-fit component has Free and Installed native states."""


class FlexibleFitState:
    fit_diameter = 20.4
    HEIGHT = 20.0
    RELIEF_WIDTH = 2.0

    def build(self):
        sleeve = Cylinder(d=self.fit_diameter, h=self.HEIGHT)
        relief = Box(12, self.RELIEF_WIDTH, 22).move(x=6)
        part = sleeve - relief

        return Configure(
            part,
            active="Free",
            columns=(Param(self.fit_diameter),),
            rows={
                "Free": ("20.4 mm",),
                "Installed": ("20.0 mm",),
            },
        )

  3. Author Free and Installed rows on the same physical component
  4. Reopen the saved design and switch to Installed
