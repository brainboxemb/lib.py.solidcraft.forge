Independent Installed state

Small / Medium / Large stays independent from the native Installed rule

Verified scpf Tube 20.0 mm; Free interference 0.2 mm; sizes 20/30/40 mm

What this model makes

A reusable split flexible sleeve keeps Small / Medium / Large as the ordinary configuration-row axis. Native SolidCraft rule evidence proves an independent Installed state can drive the shared fit parameter without replacing those rows; disabling the rule restores the active row's Free expression.

scpf/model.py
"""Native proof: size rows and Installed are independent configuration axes."""


@component(include=("fit_diameter", "sleeve_height"))
class FlexibleSleeve:
    fit_diameter = 19.8
    sleeve_height = 30.0
    RELIEF_WIDTH = 2.0

    def build(self):
        sleeve = Cylinder(d=self.fit_diameter, h=self.sleeve_height)
        relief = Box(
            12,
            self.RELIEF_WIDTH,
            self.sleeve_height + 2,
        ).move(x=6)
        return sleeve - relief


class FlexibleFitState:
    fit_diameter = 19.8
    sleeve_height = 30.0

    def build(self):
        sleeve = FlexibleSleeve(
            fit_diameter=self.fit_diameter,
            sleeve_height=self.sleeve_height,
            name="flexible_sleeve",
        )
        return Configure(
            sleeve,
            active="Medium",
            columns=(
                Param(self.sleeve_height),
                Param(self.fit_diameter),
            ),
            rows={
                "Small": ("20 mm", "19.8 mm"),
                "Medium": ("30 mm", "19.8 mm"),
                "Large": ("40 mm", "19.8 mm"),
            },
        )

Model stages

  1. Build one reusable split flexible-fit child component
  2. Keep Small / Medium / Large as ordinary configuration rows
  3. Enable Installed as a native rule that drives the shared fit parameter
  4. Switch to Large while Installed remains active
  5. Disable Installed and prove Large remains active while Free fit returns
