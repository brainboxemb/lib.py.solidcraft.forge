Parameterized Box

Three editable dimensions driving one native box

A minimal Forge model that exposes length, width and height as editable SolidCraft parameters and lowers directly to one native Box feature.

scpf source

Complete primary source from the site branch; built revision below.

scpf/model.py
"""Smallest SCPF regression example: one parameterized, editable Box."""


class SimpleBox:
    length = 40.0
    width = 30.0
    height = 10.0

    def build(self):
        return Box(
            self.length,
            self.width,
            self.height,
            anchor=Anchor.BOTTOM,
        )

pythonscad source · pass

pythonscad/model.py
"""PythonSCAD reference for the SimpleBox qualification intent.

PythonSCAD can express the same origin convention directly in cube(): the
three-character center code maps to X/Y/Z. PythonSCAD uses "-" for the side
that extends from the datum toward the positive axis, so "00-" means centered
on X and Y and extending from Z=0 to +Z. That matches Forge/SolidCraft Box
without an extra translation.
"""

from pythonscad import *


length = 40.0
width = 30.0
height = 10.0

model = cube([length, width, height], center="00-")

pybosl2/model.py
"""pyBOSL2 reference for the SimpleBox qualification intent.

pyBOSL2 cuboid() is centered by default, but its native Anchor.BOTTOM places
the bottom-face centre at Z=0. That expresses the same origin intent as
Forge/SolidCraft Box directly; no corrective translation is needed.
"""

from pybosl2 import Anchor, cuboid


length = 40.0
width = 30.0
height = 10.0

model = cuboid(
    [length, width, height],
    anchor=Anchor.BOTTOM,
)

Engineering explanation

Parameterized Box

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Legacy group: fundamentals

Saved-design required: true

Goal

Establish the smallest model/parameter contract: three public Python fields create one editable native box.

Forge API

class fields -> Parameter; Box(length, width, height); build()

Forge model

One root Shape with symbolic length, width and height; no occurrence or assembly layer.

How Forge builds it in SolidCraft

parameters.add for the public dimensions, followed directly by native solid.box; no sketch is synthesized.

SolidCraft result

One rectangular solid with the requested 40 x 30 x 10 mm dimensions and an error-free timeline.

Saved-design test

Required because this case explicitly claims an editable native Box. Change length from 40 to 50 mm in the saved .sc design; the Box must rebuild to 50 x 30 x 10 mm without rerunning Python.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: true

This case is one rectangular solid. Its body size fully describes the visible geometry. The saved SolidCraft model is checked separately to confirm that the dimensions remain editable parameters.

Reference notes

  • OpenSCAD — cube([40,30,10]) is the constructive-geometry baseline; Forge differs by preserving editable SolidCraft history.
