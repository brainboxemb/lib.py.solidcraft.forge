Face-relative hole with native pattern

One attached source cut repeated by native rectangular history

A rectangular plate with one TOP-face hole source that is cut once and repeated as an editable native rectangular pattern.

100 × 60 × 10 mm plate; two Ø8 through holes at 40 mm spacing14 generated SolidCraft commands

Model stages

  1. Create the rectangular base sketch and extrude the plate
  2. Attach one Hole sketch to the TOP face and cut through the plate
  3. Repeat the source cut with one native rectangular feature pattern

Goal

Verify one TOP-face source hole cut followed by one native rectangular history pattern.

Forge API

Forge model

A feature-based plate with one face-attached source hole cut and one native rectangular pattern that creates the second hole.

How Forge builds it in SolidCraft

Forge emits one attached Hole sketch/cut and one native solid.pattern.rectangular history feature. No Forge-side repeat helper or expanded duplicate profiles are used.

SolidCraft result

One plate with two through holes at the requested Y spacing, one source cut and one native rectangular pattern feature.

Python source

"""Face-relative Hole cut repeated by one native history pattern."""

from dataclasses import dataclass


@dataclass
class AnchoredHoles:
    """Two through holes, each 20 mm from the center along the Y axis."""

    width: float = 100
    depth: float = 60
    thickness: float = 10
    spacing: float = 40

    def build(self):
        with Sketch(name="Base", plane="XY") as sketch:
            profile = Rectangle2D(self.width, self.depth)
            sketch.add(
                profile,
                offset=(self.width / 2, self.depth / 2),
            )

        plate = sketch.extrude(self.thickness)

        with Sketch(
            name="Hole",
            on=plate,
            parent=Anchor.TOP,
        ) as hole:
            hole.add(
                Circle2D(d=8),
                offset=(
                    self.width / 2,
                    (self.depth - self.spacing) / 2,
                ),
            )

        source_cut = hole.extrude(Depth.THROUGH_ALL)
        plate = plate - source_cut

        return plate.rectangular_pattern(
            source_cut,
            count=2,
            spacing=self.spacing,
            direction=Axis.Y,
        )
