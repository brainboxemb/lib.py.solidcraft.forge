Anchors on XZ-profile extrusion

Standard corner anchors work on an XZ-authored board

A Board authored from an XZ polygon and extruded in Y exposes standard corner anchors used by independent left and right Marker components.

Board 40 × 12 × 20 mm; two 10 mm Marker cubes21 generated SolidCraft commands

Model stages

  1. Create the Board from an XZ profile
  2. Extrude the profile in Y
  3. Attach left and right Markers to standard BACK_TOP corners

Goal

Verify standard corner anchors on geometry authored as an XZ polygon and extruded in Y.

Forge API

with Sketch(plane='XZ'): Polygon2D(..., plane='XZ', world=True); sketch.extrude(...); standard corner Anchors

Forge model

Forge recovers rectangular bounds/topology from the XZ profile while preserving symbolic width and height. RightMarker and LeftMarker are separate small test parts so this case tests the board anchors, not copied-occurrence addressing.

How Forge builds it in SolidCraft

Two joint.create commands use the Board corner topology plus explicit RightMarker and LeftMarker occurrence references. No generated Component:N name is required.

SolidCraft result

Left and right markers attach to their respective front-top corners with mirrored spatial results.

Saved-design test

Change board width/height from 40x20 to 80x40 mm; both markers follow their own corners.

Geometry evidence

Are outer bounds sufficient? yes

The board and marker positions describe the visible XZ placement. After resizing the saved model, the markers must still use the same selected anchors.

Reference notes

  • OpenSCAD — The profile/extrusion resembles polygon()+linear_extrude(), but Forge retains native SolidCraft parameters and attachment topology.
  • BOSL2 — Mirrored corner anchors are a useful check that local anchor frames, not a single global direction assumption, control attachment.

Python source

class Board:
    width = 40.0
    height = 20.0
    depth = 12.0

    def build(self):
        half_width = half(self.width)
        with Sketch(name="Profile", plane="XZ") as sketch:
            Polygon2D(
                [
                    ("lower_left", (-half_width, 0)),
                    ("lower_right", (half_width, 0)),
                    ("upper_right", (half_width, self.height)),
                    ("upper_left", (-half_width, self.height)),
                ],
                plane="XZ",
                world=True,
            )
        return sketch.extrude(self.depth).with_material(
            "test board",
            density_g_cm3=0.55,
        )


class RightMarker:
    def build(self):
        return Box(10, 10, 10)


class LeftMarker:
    def build(self):
        return Box(10, 10, 10)


class XzAnchor:
    board_width = 40.0
    board_height = 20.0

    def build(self):
        board = Board(
            width=self.board_width,
            height=self.board_height,
        )
        right_marker = RightMarker().attach(
            board,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=Anchor.BACK_TOP_RIGHT,
        )
        left_marker = LeftMarker().attach(
            board,
            parent=Anchor.FRONT_TOP_LEFT,
            child=Anchor.BACK_TOP_LEFT,
        )
        return board + right_marker + left_marker
