Topology-backed corner anchor

A standard corner reference follows parent width and height

Verified scpf Base 40 × 30 × 20 mm; Marker 10 mm cube

What this verifies

A Marker uses matching parent and child corner anchors so the native relationship follows two changing parent dimensions.

scpf source

Complete primary source from the site branch; built revision below.

scpf/model.py
class Base:
    width = 40.0
    height = 20.0

    def build(self):
        return Box(self.width, 30, self.height, anchor=Anchor.BOTTOM)


class Marker:
    def build(self):
        return Box(10, 10, 10, anchor=Anchor.BOTTOM)


class CornerAnchor:
    base_width = 40.0
    base_height = 20.0

    def build(self):
        base = Base(
            width=self.base_width,
            height=self.base_height,
        )
        marker = Marker().attach(
            base,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=Anchor.BACK_TOP_RIGHT,
        )
        return base + marker

Engineering explanation

Topology-backed corner anchor

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76. Machine verification lives in verification/solidcraft.py.

Legacy group: anchors

Saved-design required: true

Goal

Verify a corner reference that follows both parent width and height changes.

Forge API

Anchor.FRONT_TOP_RIGHT paired with child Anchor.BACK_TOP_RIGHT

Forge model

A standard corner Anchor is resolved to an edge/on/corner native topology reference rather than a free point.

How Forge builds it in SolidCraft

joint.create receives SolidCraft edge/on/corner picks so the saved design can re-find the corner after geometry changes.

SolidCraft result

The marker sits on the front-top-right corner of the base.

Saved-design test

Change the base from 40x20 to 80x40 mm; the marker must follow both the new right side and new top.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: true

The base and marker positions show the intended corner placement. The saved SolidCraft model is then changed to confirm that the marker keeps following that corner.

Reference notes

  • BOSL2 — BOSL2 supports side/edge/corner anchors; its anchor also carries orientation, which is a useful design reference for Forge.
