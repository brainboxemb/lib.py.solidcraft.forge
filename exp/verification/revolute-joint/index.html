Two reusable leaves connected by a native bounded revolute relationship

Verified scpf Two 40 × 30 × 3 mm leaves; 60° initial angle; 0–180° limits

What this verifies

Qualifies Forge's public revolute attachment authoring against native SolidCraft. Two identical component occurrences share a hinge axis, start at 60 degrees, retain 0 to 180 degree limits and are driven to 120 degrees in saved-design verification.

scpf/model.py
"""Qualification: native bounded revolute relationship."""

from scpf import AnchorFrame, Box, assembly, component


@component
class Leaf:
    width = 40.0
    depth = 30.0
    thickness = 3.0

    def anchors(self):
        return {
            "hinge_positive": AnchorFrame(
                origin=(0, 15, 1.5),
                z=(1, 0, 0),
                x=(0, 0, 1),
            ),
            "hinge_negative": AnchorFrame(
                origin=(0, -15, 1.5),
                z=(1, 0, 0),
                x=(0, 0, 1),
            ),
        }

    def build(self):
        return Box(self.width, self.depth, self.thickness)


@assembly
class RevoluteFixture:
    def build(self):
        fixed = Leaf(name="fixed")
        moving = Leaf(name="moving").attach(
            fixed,
            parent="hinge_positive",
            child="hinge_negative",
            kind="revolute",
            value=60,
            limits=(0, 180),
            flip=True,
            name="Hinge",
        )
        return fixed + moving

Model stages

  1. Build one reusable leaf definition with named hinge-axis frames
  2. Create fixed and moving occurrences
  3. Create native revolute joint Hinge at the shared X axis
  4. Inspect native type, value and limits
  5. Drive Hinge from 60° to 120° and prove the moving body changes position
