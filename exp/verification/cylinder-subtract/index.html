Primitive placement semantic IR

One off-centre Cylinder cut proves shared Forge placement intent across native backends

Verified scpf 60 × 40 × 12 mm Box; Ø10 mm through bore at X=8, Y=-5

What this verifies

A bottom-anchored rectangular body is cut by an off-centre Z-axis Cylinder. Forge evaluates the SCPF source once, separates primitive geometry from PlacementIR, combines those placed primitives in BooleanSubtractIR, and lowers the same semantic intent independently to SolidCraft and Mitcad.

scpf source

scpf/model.py
"""Typed Forge placement IR qualification for an off-centre Cylinder cut."""


class CylinderSubtract:
    length = 60.0
    width = 40.0
    thickness = 12.0
    bore_d = 10.0
    bore_x = 8.0
    bore_y = -5.0

    def build(self):
        body = Box(
            self.length,
            self.width,
            self.thickness,
            anchor=Anchor.BOTTOM,
        )
        bore = Cylinder(
            d=self.bore_d,
            h=self.thickness + 20,
        ).at(
            self.bore_x,
            self.bore_y,
            0,
        )
        return body - bore

Model stages

  1. Create typed BoxIR and CylinderIR primitive geometry
  2. Place both through shared PlacementIR point and anchor semantics
  3. Normalize subtraction to BooleanSubtractIR
  4. Lower the same placed boolean to SolidCraft and Mitcad native cut operations
