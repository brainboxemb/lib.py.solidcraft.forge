Hole

Hole(*, d, depth=<Depth.THROUGH_ALL: 'through_all'>, direction=None)

Create a simple cylindrical hole feature.

When to use it

Make an ordinary drilled hole without a head recess or thread intent.

Parameters

ArgumentMeaning
dFinished hole diameter in mm.
depthHole depth in mm, or Depth.THROUGH_ALL. Defaults to through all.
directionOptional non-zero XYZ direction vector from the entry point into the material.

Example

Hole(d=4.3).at(0, 0, 2)

Current limits

d and finite depth values must be positive. Explicit native Hole features are positioned with at(); face-relative repeated simple holes may also use on() through the existing placement route.

CounterboreHole

CounterboreHole(*, d, counterbore_d, counterbore_depth, depth=<Depth.THROUGH_ALL: 'through_all'>, direction=None)

Create a hole with a cylindrical recess at its entry face.

When to use it

Seat a cylindrical screw head or other part below the entry surface.

Parameters

ArgumentMeaning
dFinished main-hole diameter in mm.
counterbore_dDiameter of the cylindrical recess in mm.
counterbore_depthDepth of the recess from the entry face in mm.
depthMain-hole depth in mm, or Depth.THROUGH_ALL. Defaults to through all.
directionOptional non-zero XYZ direction vector from the entry point into the material.

Example

CounterboreHole(
d=6,
counterbore_d=12,
counterbore_depth=4,
).at(0, 0, 12)

Current limits

counterbore_d must be larger than d. counterbore_depth and finite depth values must be positive. Position this native feature with at().

CountersinkHole

CountersinkHole(*, d, countersink_d, countersink_angle=90, depth=<Depth.THROUGH_ALL: 'through_all'>, direction=None)

Create a hole with a conical countersink at its entry face.

When to use it

Seat a countersunk fastener or specify a hole whose conical entry is part of the hole feature itself.

Parameters

ArgumentMeaning
dFinished main-hole diameter in mm.
countersink_dDiameter of the countersink at the entry face in mm.
countersink_angleIncluded countersink angle in degrees. Defaults to 90.
depthMain-hole depth in mm, or Depth.THROUGH_ALL. Defaults to through all.
directionOptional non-zero XYZ direction vector from the entry point into the material.

Example

CountersinkHole(
d=6,
countersink_d=12,
countersink_angle=90,
).at(0, 0, 12)

Current limits

countersink_d must be larger than d. countersink_angle must be between 0 and 180 degrees. Position this native feature with at().

ThreadedHole

ThreadedHole(*, thread, depth=<Depth.THROUGH_ALL: 'through_all'>, d=None, direction=None, hand='right', thread_depth=None, modeled=False, ease_out=None)

Create a tapped hole with native thread intent.

When to use it

Preserve tapped-hole manufacturing intent instead of representing the result as an ordinary cylindrical subtraction.

Parameters

ArgumentMeaning
threadThread designation such as "M6" or "1/4-20 UNC".
depthDrill depth in mm, or Depth.THROUGH_ALL. Defaults to through all.
dOptional explicit tap-drill diameter in mm. When omitted, SolidCraft selects the drill from the thread designation.
directionOptional non-zero XYZ direction vector from the entry point into the material.
handThread hand, "right" or "left". Defaults to "right".
thread_depthOptional positive threaded length in mm, independent of drill depth.
modeledWhether SolidCraft cuts modeled thread geometry. Defaults to False.
ease_outOptional modeled-thread runout: "standard", "short", or a positive length.

Example

ThreadedHole(
thread="M6",
d=5,
thread_depth=10,
modeled=True,
).at(0, 0, 12)

Current limits

The thread designation must be supported by SolidCraft. modeled=True creates actual thread geometry and can be substantially heavier than cosmetic/native thread metadata. Position this native feature with at().

Lip

Lip(*, width, height)

Create a plastic enclosure lip feature.

When to use it

Add a lip to a supported shelled enclosure rim using feature placement.

Parameters

ArgumentMeaning
widthLip width in mm.
heightLip height in mm.

Example

Lip(width=2, height=3)

Current limits

width and height must be positive when compiled. Placement and parent-shape support follow the feature-placement API.

SnapFit

SnapFit(*, length, thickness, width, catch_depth, catch_length, hook, direction=None)

Create a cantilever snap-fit feature.

When to use it

Add a plastic snap feature to a supported face with an explicit hook direction.

Parameters

ArgumentMeaning
lengthCantilever length in mm.
thicknessCantilever thickness in mm.
widthCantilever width in mm.
catch_depthCatch projection depth in mm.
catch_lengthCatch length in mm.
hookNon-zero XYZ direction vector for the hook direction.
directionOptional non-zero XYZ direction vector for the feature direction.

Example

SnapFit(length=20, thickness=2, width=8, catch_depth=1.5, catch_length=4, hook=(1, 0, 0))

Current limits

All five dimensions must be positive when compiled. hook must contain three coordinates; direction, when supplied, must also contain three.

Boss

Boss(*, d, h, hole_d=None, direction=None)

Create a plastic screw-boss feature.

When to use it

Add a cylindrical support boss, optionally with a central hole, to a supported face.

Parameters

ArgumentMeaning
dBoss outside diameter in mm.
hBoss height in mm.
hole_dOptional central-hole diameter in mm.
directionOptional non-zero XYZ direction vector for the boss axis.

Example

Boss(d=7, h=12, hole_d=2.5)

Current limits

d and h must be positive when compiled. hole_d, when supplied, must be positive. direction, when supplied, must contain three coordinates.

Rest

Rest(*, width, height, length=None, along=None, direction=None)

Create a plastic support/rest feature.

When to use it

Add a support pad or elongated rest to a supported face.

Parameters

ArgumentMeaning
widthRest width in mm.
heightRest height in mm.
lengthOptional rest length in mm for an elongated support.
alongOptional non-zero XYZ vector that sets the long direction.
directionOptional non-zero XYZ vector that sets the feature direction.

Example

Rest(width=12, height=4, length=30, along=(1, 0, 0))

Current limits

width and height must be positive when compiled. length, when supplied, must be positive. along and direction must contain three coordinates.
