Parameters and positioning helpers

Keep dimensions symbolic and express readable offsets or parent-bound positions.

Worked usage in the guide → · Cross-object API design rules →

Parameter

Parameter(name: str, value: float) -> None

Represent one named editable CAD dimension.

When to use it

Keep a value symbolic so generated SolidCraft commands can retain an editable dependency instead of baking in the current Python number.

Parameters

ArgumentMeaning
nameSolidCraft parameter name. It must be a valid Python identifier.
valueCurrent numeric value of the parameter.

Example

wall = Parameter("wall", 2.4)

Current limits

value must be finite. Normal public lower-case model fields are usually promoted to parameters automatically, so explicit Parameter() is mainly useful in lower-level or assembly code.

Placement

Placement(x: object = 0, y: object = 0, z: object = 0, rotation: tuple[object, object] | None = None) -> None

Absolute pose of one occurrence in its parent coordinate frame.

When to use it

Declare the pose of a component occurrence at creation or copy time.

Parameters

ArgumentMeaning
xAbsolute X position in mm. May be numeric, Parameter or Expression.
yAbsolute Y position in mm. May be numeric, Parameter or Expression.
zAbsolute Z position in mm. May be numeric, Parameter or Expression.
rotationOptional (axis, degrees) absolute rotation. axis may be X/Y/Z, Axis, or a non-zero XYZ vector.

Example

Placement(x=160, z=20, rotation=(Axis.Z, 90))

Current limits

Placement is occurrence creation state, not a relative move action. Coordinates, rotation axis and angle must evaluate to finite values.

X

X = X

Axis token with MIN, CENTER and MAX parent-bound placement selectors.

When to use it

Public X, Y and Z tokens let feature offsets refer to a parent bound, for example X.MIN + 10 or Y.MAX - 10, without hard-coding the current global coordinate.

Current limits

These X/Y/Z tokens are bound selectors, not Axis.X/Y/Z primitive-axis enum values.

up

up(distance)

Return a symbolic-safe XYZ offset in the +Z direction.

When to use it

Express a readable placement offset while preserving Parameter or Expression values.

Parameters

ArgumentMeaning
distanceNumeric or symbolic CAD distance in mm.

Example

offset = up(12)

Current limits

This returns an XYZ tuple; it does not create an Anchor relationship.

half

half(value)

Return half of a numeric or symbolic CAD dimension.

When to use it

Keep midpoint-style arithmetic readable without converting a symbolic CAD dimension to a concrete Python value.

Parameters

ArgumentMeaning
valueNumeric, Parameter or Expression value to divide by two.

Example

centre = half(width)

Current limits

Equivalent to value / 2; the input must support that operation.

midpoint

midpoint(start, end)

Return the midpoint between two numeric or symbolic dimensions.

When to use it

Express a centre position while preserving symbolic CAD dependencies.

Parameters

ArgumentMeaning
startFirst numeric or symbolic coordinate/dimension.
endSecond numeric or symbolic coordinate/dimension.

Example

centre_x = midpoint(left_x, right_x)

Current limits

Equivalent to (start + end) / 2; inputs must support symbolic arithmetic.

pv

pv(dim) -> float

Return the concrete Python value of a symbolic CAD dimension.

When to use it

Python itself genuinely needs a number for validation or control flow.

Parameters

ArgumentMeaning
dimNumeric value, Parameter or Expression to read as a Python float.

Example

if pv(clearance) < 0:
raise ValueError("clearance must not be negative")

Current limits

Calling pv() intentionally removes the symbolic dependency at that point. Geometry and placement should normally keep Parameter/Expression objects symbolic so SolidCraft remains editable and associative.
