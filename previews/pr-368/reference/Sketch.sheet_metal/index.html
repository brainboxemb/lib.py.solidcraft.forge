API Reference / Sketch.sheet_metal()

Generated SCPF API reference

Sketch.sheet_metal()

Create a native sheet-metal body from this closed flat Sketch.

Current Python signature

Sketch.sheet_metal(self, *, thickness, bend_radius, k_factor=0.5, rule_name='Forge Sheet')

When to use it

Start a fabricated sheet part from its flat blank before applying holes, folds, hems or other sheet-metal features.

Current limits

The first qualified form requires one standalone XY Sketch with one closed profile. Leave the Sketch scope before creating the sheet.
