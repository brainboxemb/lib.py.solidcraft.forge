AnchorFrame

AnchorFrame(origin: tuple[float, float, float] = (0.0, 0.0, 0.0), z: tuple[float, float, float] | scpf.core.Anchor = <Anchor.TOP: 'top'>, x: tuple[float, float, float] | scpf.core.Anchor = <Anchor.RIGHT: 'right'>) -> None

Describe one local attachment point and orientation.

When to use it

A standard face or corner Anchor is not enough and the mounting datum needs its own local origin plus orientation. A reusable component may expose named AnchorFrame values from anchors(), or an assembly may pass one directly to attach().

Parameters

ArgumentMeaning
originComponent-local XYZ attachment point in mm. Defaults to (0, 0, 0).
zAttachment-normal direction as an XYZ vector or Anchor. Defaults to Anchor.UP.
xLocal X/clocking direction as an XYZ vector or Anchor. Defaults to Anchor.RIGHT.

Example

mount = AnchorFrame(origin=(20, 0, 10), z=Anchor.FRONT, x=Anchor.RIGHT)

Current limits

z and x must be non-zero and must not be parallel. Direct frames on explicitly rotated occurrences have limited support as documented by the assembly guide.

AnchorTopology

AnchorTopology(edge: tuple[float, float, float], on: tuple[float, float, float], corner: tuple[float, float, float] | None = None, z: tuple[float, float, float] | None = None, x: tuple[float, float, float] | None = None) -> None

Describe an attachment datum that follows native SolidCraft topology.

When to use it

A relationship should follow a particular edge, adjacent planar face and optionally one endpoint as dimensions change, rather than freezing one XYZ coordinate.

Parameters

ArgumentMeaning
edgeXYZ pick point on the target edge, in component-local mm.
onXYZ pick point on the adjacent planar face, in component-local mm.
cornerOptional XYZ endpoint/corner pick in component-local mm.
zOptional non-zero XYZ attachment-normal override.
xOptional non-zero XYZ clocking-direction override.

Example

mount = AnchorTopology(edge=(0, 25, 10), on=(0, 20, 10), corner=(0, 25, 0))

Current limits

edge and on are native selection pick points. Current Forge support focuses on planar-face edges and non-rotated occurrences. z and x, when both supplied, must not be parallel.
