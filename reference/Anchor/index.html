Anchor

Select component attachment references and cardinal directions.

When to use it

Use cardinal or corner anchors to attach reusable component occurrences, or combine cardinal values to identify Box edges/corners.

Convenience aliases

Current limits

Anchor is the assembly/alignment vocabulary. Within-component feature placement normally uses Faces instead. INNER_BOTTOM has no direction vector and therefore cannot be used as a cardinal selector.
