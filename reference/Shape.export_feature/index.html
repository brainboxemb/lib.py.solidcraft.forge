Shape.export_feature

Export one exact Forge-authored feature through a reusable component definition.

Related guide

Signature 

Shape.export_feature(self, name)

Use when

A parent configuration must suppress a feature authored inside a reusable child without exposing SolidCraft history ids.

Limits

The name is component-local Forge identity. Export an already-authored suppressible feature that is part of the final child Shape; this does not make whole-component presence a feature-suppression operation.

Parameters

  • name — Public component-local Forge export name.

Example 

panel_pin = Hole(d=5).at(0, 0, 12).export_feature("panel_pin")
