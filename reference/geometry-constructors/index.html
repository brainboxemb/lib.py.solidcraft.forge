Box

Box(length, width, thickness, *, anchor=<Anchor.CENTER: 'center'>)

Create a native rectangular solid around a declared anchor datum.

When to use it

Model a simple rectangular part directly without introducing a Sketch.

Parameters

ArgumentMeaning
lengthBox size along X, in mm.
widthBox size along Y, in mm.
thicknessBox size along Z, in mm.
anchorBox datum placed at model coordinate (0, 0, 0) before later placement. Defaults to Anchor.CENTER.

Example

Box(80, 50, 12, anchor=Anchor.BOTTOM)

Current limits

The default anchor is CENTER, so an unplaced Box is centred around the model origin in X, Y and Z. Use anchor=BOTTOM for a box whose bottom face centre is at Z=0. Use at() for later placement.

Cylinder

Cylinder(*, d, h, axis=<Axis.Z: 'Z'>, anchor=<Anchor.CENTER: 'center'>)

Create a cylindrical solid centred around the origin by default.

When to use it

Model a cylinder along Axis.X, Axis.Y or Axis.Z. Use BOTTOM for a Z-axis base, LEFT for an X-axis base or FRONT for a Y-axis base.

Parameters

ArgumentMeaning
dCylinder diameter in mm.
hCylinder length along the selected axis, in mm.
axisCylinder axis. Use Axis.X, Axis.Y or Axis.Z. Defaults to Axis.Z.
anchorCylinder datum placed at model coordinate (0, 0, 0) before later placement. Defaults to Anchor.CENTER.

Example

Cylinder(d=8, h=20, axis=Axis.X, anchor=Anchor.LEFT)

Current limits

Anchors refer to world XYZ bounds after choosing the cylinder axis. at() places the selected anchor at the requested coordinate.

Cone

Cone(*, d, top_d=0, h, axis=<Axis.Z: 'Z'>, anchor=<Anchor.CENTER: 'center'>)

Create a native cone or tapered cylinder (frustum).

When to use it

Model a cone, tapered pin or lightly conical cylinder directly with SolidCraft's native solid.cone feature.

Parameters

ArgumentMeaning
dDiameter at the base end, in mm.
top_dDiameter at the other end, in mm. Defaults to 0 for a full cone.
hLength along the selected axis, in mm.
axisCone axis. Use Axis.X, Axis.Y or Axis.Z. Defaults to Axis.Z.
anchorCENTER or one of the two axial end datums.

Example

Cone(d=20, top_d=20.2, h=20, anchor=Anchor.BOTTOM)

Current limits

Because the two end radii may differ, transverse tangent anchors are intentionally not exposed. Use CENTER or the selected axis' two end anchors: LEFT/RIGHT for X, FRONT/BACK for Y, BOTTOM/TOP for Z.

Sphere

Sphere(radius, *, anchor=<Anchor.CENTER: 'center'>)

Create a sphere centred on the origin unless another anchor is given.

When to use it

Model a spherical primitive, optionally with a tangent-point anchor.

Parameters

ArgumentMeaning
radiusSphere radius in mm.
anchorSphere datum placed at model coordinate (0, 0, 0) before later placement. Defaults to Anchor.CENTER.

Example

Sphere(12, anchor=Anchor.BOTTOM)

Current limits

Cardinal anchors select points on the sphere's world-aligned bounds. Sphere has no separate orientation axis; use at() for placement.

Rectangle2D

Rectangle2D(width, depth)

Create a rectangular 2D profile.

When to use it

Author a simple rectangle inside an explicit Sketch before extrusion.

Parameters

ArgumentMeaning
widthRectangle size along the first local sketch axis, in mm. On XY this is X.
depthRectangle size along the second local sketch axis, in mm. On XY this is Y.

Example

Rectangle2D(80, 50)

Current limits

The dimension-defined profile is centred on the Sketch origin by default. Use Sketch.add(..., offset=(u, v)) for a deliberate local displacement.

RoundedRectangle2D

RoundedRectangle2D(width, depth, radius)

Create a native rounded-rectangle 2D profile.

When to use it

A sketch needs a rectangle with true circular corner arcs rather than a polygonal approximation.

Parameters

ArgumentMeaning
widthRectangle size along the first local sketch axis, in mm.
depthRectangle size along the second local sketch axis, in mm.
radiusRadius of each corner arc, in mm.

Example

RoundedRectangle2D(80, 50, 6)

Current limits

Current support is inside an explicit Sketch. width and depth must be positive. radius must be positive and below half the shorter side.

Circle2D

Circle2D(*, d=None, r=None)

Create a circular 2D profile by diameter or radius.

When to use it

Author a circular profile inside an explicit Sketch.

Parameters

ArgumentMeaning
dCircle diameter in mm. Supply d or r, not both.
rCircle radius in mm. Supply r or d, not both.

Example

Circle2D(d=8)

Current limits

Supply exactly one of d= or r=. The Sketch determines the plane.

Polygon2D

Polygon2D(points, *, plane='XY', ids=None, world=False)

Create a closed named or unnamed polygon profile.

When to use it

A 2D profile needs arbitrary straight segments or named vertices and segments that later drive selectors such as Edges.from_profile().

Parameters

ArgumentMeaning
pointsPolygon vertices in order. Use (u, v) pairs, or (name, (u, v)) pairs when naming vertices, in mm.
planeSketch plane: "XY", "XZ" or "YZ". Defaults to "XY".
idsOptional segment names, one per polygon edge in vertex order.
worldWhen True with plane="XZ", read each input point as world (x, z) instead of native sketch coordinates.

Example

Polygon2D([(0, 0), (40, 0), (40, 20), (0, 20)], plane="XY")

Current limits

At least three 2D points are required. Named and unnamed points cannot be mixed. world=True currently supports only plane="XZ".
