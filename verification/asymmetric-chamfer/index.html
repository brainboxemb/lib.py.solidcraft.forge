Verification

Native asymmetric chamfer

One semantic edge set keeps two independent native chamfer distances

Verified scpf 40 × 20 × 10 mm body; 0.18 / 0.65 mm chamfer

What this verifies

A named top segment on an XZ profile selects the two broad-face edges of one extrusion. SolidCraft stores one ChamferFeature with independent primary and secondary distances and preserves it when the saved design is resized.

scpf/model.py
"""Native two-distance chamfer qualification."""


class AsymmetricChamfer:
    width = 40.0
    depth = 20.0
    height = 10.0
    primary_distance = 0.18
    secondary_distance = 0.65

    def build(self):
        with Sketch(name="Chamfer profile", plane="XZ") as profile:
            Polygon2D(
                [
                    (-self.width / 2, 0),
                    (self.width / 2, 0),
                    (self.width / 2, self.height),
                    (-self.width / 2, self.height),
                ],
                plane="XZ",
                world=True,
                ids=["bottom", "right", "top", "left"],
            )

        body = profile.extrude(self.depth, sym=True)
        return body.chamfer(
            self.primary_distance,
            distance2=self.secondary_distance,
            flip=True,
            edges=Edges.from_profile("top"),
        )

Model stages

  1. Create one named rectangular XZ profile
  2. Extrude it symmetrically along Y
  3. Apply one two-distance native chamfer to the named top profile edge
