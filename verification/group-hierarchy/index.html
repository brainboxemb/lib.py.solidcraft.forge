scpf/model.py
"""Qualification: group(name) becomes a real nested native component."""


class Panel:
    def build(self):
        return Box(10, 2, 20, anchor=Anchor.BOTTOM)


class Frame:
    def build(self):
        # The frame offset is visual fixture geometry, not the grouping API.
        return Box(35, 10, 40, anchor=Anchor.BOTTOM).move(y=20)


class GroupHierarchy:
    def build(self):
        left = Panel()
        panels = (left + left.copy(placement=Placement(x=11))).group("PanelGroup")
        frame = Frame()
        return panels + frame

Engineering explanation

Named native subassembly group

Documentation provenance: the engineering text below is copied verbatim from the last canonical qualification/cases.py source before its removal, commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Legacy group: components

Goal

Verify that group(name) creates a real nested native component rather than a Python-only label.

Forge API

(left + right).group(‘PanelGroup’); group + Frame()

Forge model

Two Panel occurrences share one definition under a named PanelGroup component, while Frame remains a direct root child.

How Forge builds it in SolidCraft

Forge emits component.create(name=‘PanelGroup’), creates Panel with parent=‘PanelGroup’, copies its occurrence, and creates Frame at the design root.

SolidCraft result

Two 10 x 2 x 20 mm panels remain nested under PanelGroup and one 35 x 10 x 40 mm frame remains at root; native BOM inspection must preserve that hierarchy.

Saved-design test

No saved-design mutation in this fixture; it isolates persisted native grouping and hierarchy.

Geometry evidence

Geometry-rationale provenance: copied verbatim from qualification/geometry_contracts.py at commit be40b09e7454a90e87d83768a9e7453c52ba5d76.

Bounds sufficient: true

The body sizes describe the visible parts. The saved SolidCraft model is checked separately to confirm the expected group and BOM structure.

Reference notes

  • SolidCraft — Native components form a tree; top-level BOM inspection exposes direct children while flat BOM inspection expands subassemblies.
  • PythonSCAD — Python-side composition should lower to inspectable native CAD structure rather than remain a transient wrapper.

cadquery/model.py
"""CadQuery assembly reference for grouped panels plus a separate frame.

This compares nested assembly intent and visible geometry. SolidCraft BOM
persistence remains native Forge qualification evidence.
"""

import cadquery as cq


panel = cq.Solid.makeBox(
    10,
    2,
    20,
    cq.Vector(-5, -1, 0),
)
frame = cq.Solid.makeBox(
    35,
    10,
    40,
    cq.Vector(-17.5, -5, 0),
)

panel_group = cq.Assembly(name="PanelGroup")
panel_group.add(panel, name="panel_1", loc=cq.Location((0, 0, 0)))
panel_group.add(panel, name="panel_2", loc=cq.Location((11, 0, 0)))

model = cq.Assembly()
model.add(panel_group, name="panels")
model.add(frame, name="frame", loc=cq.Location((0, 20, 0)))

"""build123d reference: two panels plus a separate frame.

The builder compares visible geometry; SolidCraft-native qualification proves
browser hierarchy and BOM persistence.
"""
from build123d import Align, Box, BuildPart, Locations

bottom = (Align.CENTER, Align.CENTER, Align.MIN)

with BuildPart() as model:
    with Locations((0, 0, 0), (11, 0, 0)):
        Box(10, 2, 20, align=bottom)
    with Locations((0, 20, 0)):
        Box(35, 10, 40, align=bottom)
