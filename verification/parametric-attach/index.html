Editable distance between attached components

Verify that distance along the attachment normal remains a native editable joint parameter.

Forge code

This is the complete Forge source used for this example.

class Base:
    def build(self):
        return Box(40, 30, 10, anchor=Anchor.BOTTOM)


class Block:
    def build(self):
        return Box(20, 20, 10, anchor=Anchor.BOTTOM)


class ParametricAttach:
    gap = 10.0

    def build(self):
        base = Base()
        block = Block().attach(
            base,
            parent=Anchor.RIGHT,
            child=Anchor.LEFT,
            gap=self.gap,
        )
        return base + block

"""pyBOSL2 anchor reference for a right-side attachment with a gap.

pyBOSL2 calls the signed face separation overlap; a negative overlap is a gap.
Forge additionally qualifies saved SolidCraft parameter mutation of this value.
"""

from pybosl2 import Anchor, cuboid

gap = 10.0
base = cuboid([40, 30, 10]).up(5)
block = cuboid([20, 20, 10]).up(5)
model = base.attach(
    Anchor.RIGHT,
    block,
    child_anchor=Anchor.LEFT,
    overlap=-gap,
).realize()

gap, base_width, child_width = 10.0, 40.0, 20.0

with BuildPart() as model:
    Box(base_width, 30, 10, align=bottom)
    with Locations((base_width / 2 + child_width / 2 + gap, 0, 0)):

Engineering explanation

Forge API

attach(..., gap=self.gap)

Forge model

Rigid Attachment with a symbolic gap expression; anchor identities are unchanged.

How Forge builds it in SolidCraft

The child receives a symbolic seed pose so a floating graph starts at the authored mating position; joint.create(type='rigid', offset='gap') remains the relationship and the gap remains a native expression in both places rather than a flattened number.

SolidCraft result

The child sits 10 mm away from the parent's RIGHT face along the joint normal.

Saved-design test

Change gap from 10 to 30 mm in the saved .sc design; the child must move another 20 mm without rerunning Python.

Geometry evidence

Are outer bounds sufficient? yes

The two rectangular body bounds describe the baseline gap geometry. Saved joint recompute is proved separately by saved-design.

Reference notes

  • BOSL2 — Conceptually similar to an attachment displacement along the local anchor normal rather than a world-axis translate.
