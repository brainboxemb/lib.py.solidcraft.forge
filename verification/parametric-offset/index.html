Editable local offset at an attachment

What this example makes

The marker moves within the selected corner anchor's local attachment plane.

Forge code

This is the complete Forge source used for this example.

class Base:
    def build(self):
        return Box(40, 30, 20, anchor=Anchor.BOTTOM)


class Marker:
    def build(self):
        return Box(10, 10, 10, anchor=Anchor.BOTTOM)


class ParametricOffset:
    shift = 5.0

    def build(self):
        base = Base()
        marker = Marker().attach(
            base,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=Anchor.BACK_TOP_RIGHT,
            offset=(0, -self.shift),
        )
        return base + marker


ParametricOffset()

API used

"""PythonSCAD geometry reference for a corner marker with local planar shift.

Forge additionally qualifies that the saved SolidCraft joint follows a changed
shift parameter without rerunning Python.
"""

from pythonscad import *

shift = 5.0
base = cube([40, 30, 20], center=True).up(10)
marker = cube([10, 10, 10], center=True).translate([15, -20, 20])
model = base | marker

"""CadQuery geometry reference for a corner marker with a planar shift.

The final Location compares the visible local-offset result. Forge separately
qualifies persisted local joint-frame mutation in SolidCraft.
"""

import cadquery as cq


shift = 5.0
base = cq.Solid.makeBox(40, 30, 20, cq.Vector(-20, -15, 0))
marker = cq.Solid.makeBox(10, 10, 10, cq.Vector(-5, -5, -5))

model = cq.Assembly()
model.add(base, name="base")
model.add(marker, name="marker", loc=cq.Location((15, -20, 20)))

"""build123d reference: a marker shifted relative to a top/front corner."""
from build123d import Align, Box, BuildPart, Locations

shift = 5.0
bottom = (Align.CENTER, Align.CENTER, Align.MIN)

with BuildPart() as model:
    Box(40, 30, 20, align=bottom)
    with Locations((15, -15 - shift, 20)):
        Box(10, 10, 10)

How Forge builds it in SolidCraft

The computed child seed pose retains the symbolic local offset, then the actual relationship is joint.create(type='planar', values=[u,v,angle]). The seed move is not an additional joint.

Reference documentation

  • BOSL2 — Important reference: attach() operates in the local coordinate system at the parent anchor, not blindly in world coordinates.
  • OpenSCAD — A raw translate([x,y,z]) is world/object transform syntax and therefore is not equivalent to this local joint offset.
