Minimal L-profile

Provide a deliberately simple reusable L-shaped reference component for later attachment/orientation qualification.

Forge code

This is the complete Forge source used for this example.

@dataclass
class Bracket:
    """Minimal L-profile qualification fixture.

    Deliberately no holes, fillets or secondary features: this fixture exists
    to verify profile geometry, XZ extrusion and later assembly relationships
    without unrelated feature behavior obscuring the result.
    """

    width: float = 24
    arm_length: float = 40
    arm_height: float = 12

    def build(self):
        with Sketch(name="Profile", plane="XZ") as sketch:
            Polygon2D(
                [
                    (0, 0),
                    (self.arm_length, 0),
                    (self.arm_length, self.arm_height),
                    (self.arm_height, self.arm_height),
                    (self.arm_height, self.arm_length),
                    (0, self.arm_length),
                ],
                plane="XZ",
            )
        return sketch.extrude(self.width, sym=True)

"""PythonSCAD geometry reference for the minimal symmetric L bracket."""

from pythonscad import *

def box_bounds(lo, hi):
    size = [hi[i] - lo[i] for i in range(3)]
    center = [(hi[i] + lo[i]) / 2 for i in range(3)]
    return cube(size, center=True).translate(center)

horizontal = box_bounds([0, -12, -12], [40, 12, 0])
vertical = box_bounds([0, -12, -40], [12, 12, 0])
model = horizontal | vertical

Engineering explanation

Forge API

with Sketch(plane='XZ'): Polygon2D(..., plane='XZ'); sketch.extrude(width, direction=Direction.SYMMETRIC)

Forge model

One symbolic L profile extruded symmetrically through its width; no holes, fillets, anchors or secondary features.

How Forge builds it in SolidCraft

Native XZ sketch/polygon plus symmetric extrusion. No assembly commands are present yet.

SolidCraft result

A clean 40 mm L profile with 12 mm arms and 24 mm symmetric extrusion width.

Saved-design test

Not yet an attachment mutation case. This component is intentionally the geometry baseline for upcoming multi-orientation anchor tests.

Geometry evidence

Are outer bounds sufficient? no

A filled box can share the L-profile envelope. L-profile volume and a probe in the missing corner are required.

Reference notes

  • OpenSCAD — Equivalent baseline is a 2D L polygon followed by linear_extrude(center=true).
  • BOSL2 — Later attachment cases can reuse this simple shape while testing anchor/orient semantics independently of bracket feature complexity.
