Multi-profile annular Sketch extrusion

Two concentric closed loops become one native hollow extrusion

Verified scpf Ø10 outer; Ø8 inner; 30 mm length

What this verifies

One standalone Sketch owns concentric Ø10 and Ø8 circles. One exact-region extrusion selects the annulus and preserves it as a single native extrusion when the saved design dimensions change.

scpf source

Complete primary source from the site branch; built revision below.

scpf/model.py
"""Native multi-profile standalone Sketch extrusion qualification."""


class MultiProfileExtrude:
    outer_diameter = 10.0
    inner_diameter = 8.0
    length = 30.0

    def build(self):
        with Sketch(name="Tube profile", plane="XY") as profile:
            Circle2D(d=self.outer_diameter)
            Circle2D(d=self.inner_diameter)

        return profile.extrude(
            self.length,
            profiles=[(4.5, 0)],
            exact_regions=True,
        )

Model stages

  1. Create one standalone XY Sketch with two concentric Circle2D profiles
  2. Select the annular region between the loops
  3. Extrude that exact region as one native hollow body
