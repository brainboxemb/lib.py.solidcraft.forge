API Guide / Features and references

Features and references

Native holes, fillets, shells and relative positioning.

A feature changes an existing body

A native feature is different from subtracting arbitrary CSG geometry. SCPF can retain named sketches and operations in SolidCraft history. For exact results, supported body types and selection constraints matter.

Holes

from scpf import Box, Hole, Depth, Faces

plate = Box(100, 60, 10)
hole = Hole(d=8, depth=Depth.THROUGH_ALL)
plate = plate + hole.on(plate, face=Faces.TOP)

A Hole is a native hole feature: adding it to the shape means adding the operation that removes material. Faces.TOP selects its entry face. Simple feature placement uses on(); assembly attachment uses explicit anchors.

Native feature patterns

Pattern an already-applied native feature when the copies should remain one editable SolidCraft history operation. Rectangular and circular patterns share the same source-feature rules: the source is a Sketch.extrude() feature that is already part of the body, and a direct count Parameter remains editable in the saved design.

from scpf import Anchor, Axis, Box, Circle2D, Depth, Sketch

plate = Box(100, 80, 6, anchor=Anchor.BOTTOM)
with Sketch(name="BoltHole", on=plate, parent=Anchor.TOP) as bolt:
    bolt.add(Circle2D(d=8), offset=(30, 0))

cut = bolt.extrude(Depth.THROUGH_ALL)
plate = plate - cut

bolt_circle = plate.circular_pattern(
    cut,
    count=6,
    axis=Axis.Z,
)

circular_pattern() omits angle by default so SolidCraft uses its native 360-degree full-circle behaviour. Supply a fixed degree value or direct Parameter for a partial arc. origin=(x, y, z) moves a fixed axis; a fixed non-zero XYZ vector can be used instead of Axis.X/Y/Z. Construction-axis and geometry-axis selectors are not yet exposed by Forge.

grid = plate.rectangular_pattern(
    cut,
    count=4,
    spacing=20,
    direction=Axis.X,
    count2=3,
    spacing2=18,
    direction2=Axis.Y,
)

rectangular_pattern() and circular_pattern() both emit one native feature-pattern command rather than expanding independent copies in Python.

Fillets and chamfers

from scpf import FRONT, LEFT, Box, Edges

body = Box(80, 50, 15)
rounded = body.fillet(3, edges=Edges.VERTICAL)
bevelled = body.chamfer(3, edges=Edges.VERTICAL)
one_edge = body.chamfer(3, edges=FRONT + LEFT)

fillet() and chamfer() use the same edge-selection forms. Use Edges.VERTICAL for all vertical edges of a supported rectangular body, a two-direction selector such as FRONT + LEFT for one Box edge, Edges.from_profile(...) or Edges.from_vertices(...) for named Polygon2D geometry, or explicit XYZ pick coordinates. Both methods default to Edges.VERTICAL. A topological edge cannot always be inferred reliably from a visual camera position.

Shells

from scpf import Box, Faces
case = Box(80, 50, 30).shell(2, open=Faces.TOP)

Faces.TOP chooses the face to open and is also the same surface-selection vocabulary used by feature.on(...). Anchor is reserved for explicit component attachment in assemblies. See the source and regression tests for supported feature chains.

Feature placement without hard-coded global offsets

from scpf import X, Y, Boss, Anchor

boss = Boss(d=7, h=12, hole_d=2.5).attach(
    case, parent=Anchor.INNER_BOTTOM,
    offset=(X.MIN + 10, Y.MAX - 10),
)

X.MIN and Y.MAX refer to the parent bounds and are not rotation-axis constants. Anchoring support currently focuses on rectangular bases and a documented set of faces. Do not assume every curved or lofted surface supports it.

API on this page

These values and signatures are generated from the current Python API. They are shown here so the normal guide flow does not require opening the reference for every detail.

Faces

Select named planar faces for within-component feature operations.

Faces.TOP · Faces.BOTTOM · Faces.LEFT · Faces.RIGHT · Faces.FRONT · Faces.BACK

Use when: Pass a Faces value to operations such as Shape.on() and Shape.shell() to identify a surface of the target body.

Current limits: The enum defines all six cardinal faces. Individual operations may support only a subset; Shape.on() currently accepts TOP and BOTTOM. Component assembly attachment uses Anchor instead.

Depth

Choose a supported feature-depth policy.

Depth.THROUGH_ALL

Use when: Use Depth.THROUGH_ALL for features such as Hole that should pass completely through their target instead of using a fixed distance.

Current limits: THROUGH_ALL is currently the only named depth policy.

Edges

Select edges for supported fillet and chamfer feature operations.

Edges.VERTICAL

Use when: Use Edges.VERTICAL for the vertical edges of a supported rectangular body. Use from_profile() for named profile segments and from_vertices() for extrusion-axis edges grown from named profile vertices.

Current limits: Only the selectors implemented here are public. from_profile() currently supports sides="both"; from_vertices() requires named Polygon2D vertices.

Shape.on()

Place a supported within-component feature on a target face.

Shape.on(self, target, *, face=<Faces.TOP: 'top'>, offset=(0, 0))

Use when: Put a Hole or another supported feature on an existing Shape and select its entry/support surface with Faces.

Current limits: Shape.on() currently accepts Faces.TOP and Faces.BOTTOM. This is feature placement; component assembly attachment uses Anchor and the component occurrence attach() API.

Shape.attach()

Anchor a supported feature explicitly to another Shape.

Shape.attach(self, target, *, parent=<Anchor.TOP: 'top'>, child=<Anchor.BOTTOM: 'bottom'>, offset=(0, 0))

Use when: Use this lower-level feature-placement form when parent/child Anchor references are required explicitly.

Current limits: This is legacy within-component feature anchoring. Prefer on() for simple face placement. It is separate from component occurrence attachment used by assemblies.

Shape.fillet()

Round selected solid edges with one radius.

Shape.fillet(self, radius, *, edges=<Edges.VERTICAL: 'vertical'>)

Use when: Round one or more edges of a supported feature-based body. Fillet and chamfer use the same edge-selection forms.

Current limits: Edges.VERTICAL and cardinal Box edge selectors require a supported rectangular body. Named profile/vertex selectors require matching Polygon2D ids in a supported extrusion.

Shape.chamfer()

Chamfer selected solid edges by one equal distance.

Shape.chamfer(self, distance, *, edges=<Edges.VERTICAL: 'vertical'>)

Use when: Bevel one or more edges of a supported feature-based body. Chamfer and fillet use the same edge-selection forms.

Current limits: Edges.VERTICAL and cardinal Box edge selectors require a supported rectangular body. Named profile/vertex selectors require matching Polygon2D ids in a supported extrusion.

Shape.shell()

Hollow a supported solid and leave selected Faces open.

Shape.shell(self, thickness, *, open=<Faces.TOP: 'top'>)

Use when: Create an enclosure-like body with an even wall thickness while removing one or more named planar faces.

Current limits: open= must be one Faces value or a non-empty sequence of Faces values. Support still depends on the underlying feature tree.

Shape.fold()

Fold existing sheet material along one straight line.

Shape.fold(self, *, line, angle=90, fixed=None, position='centerline', flip=False)

Use when: Bend material that already exists in a sheet blank. Dimensions and bend allowance come from the sheet's shared rule.

Current limits: This first qualified form supports one straight fold line. The line endpoints and fixed point are fixed finite coordinates.

Shape.rectangular_pattern()

Pattern an existing native history feature in one or two directions.

Shape.rectangular_pattern(self, feature, *, count, spacing, direction=<Axis.X: 'X'>, count2=None, spacing2=None, direction2=<Axis.Y: 'Y'>, alignment='right', alignment2='right', reversed=False, reversed2=False)

Use when: Repeat an already-created native sketch extrusion while keeping one editable SolidCraft rectangular-pattern history feature.

Current limits: The source feature must already be part of this Shape. Supplying a second direction requires both count2 and spacing2.

Shape.circular_pattern()

Pattern an existing native history feature around a fixed axis.

Shape.circular_pattern(self, feature, *, count, axis=<Axis.Z: 'Z'>, angle=None, origin=None, alignment='right', reversed=False)

Use when: Repeat an already-created native sketch extrusion around an axis while keeping one editable SolidCraft circular-pattern history feature, for example a bolt circle.

Current limits: The source feature must already be part of this Shape. Axis values cover principal or fixed XYZ axes. Native construction-axis, edge-axis and face-axis selectors are not exposed yet.

Feature constructors

Mechanical Hole-family and plastic-feature intent added to supported bodies.

Hole

Hole(*, d, depth=<Depth.THROUGH_ALL: 'through_all'>, direction=None)

Create a simple cylindrical hole feature.

Use when: Make an ordinary drilled hole without a head recess or thread intent.

Current limits: d and finite depth values must be positive. Explicit native Hole features are positioned with at(); face-relative repeated simple holes may also use on() through the existing placement route.
