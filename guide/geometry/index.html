Geometry, sketches and Boolean operations

Solids, 2D profiles, extrusions and the CSG operators.

Start with a solid

Box, Cylinder and Sphere are centred on their geometric CENTER by default. Use anchor=... when a face, axial end or tangent datum should lie at the origin. For Cylinder the anchor is resolved after choosing Axis.X, Axis.Y or Axis.Z; for example LEFT/RIGHT are the axial ends of an X-axis cylinder and BOTTOM/TOP are the axial ends of a Z-axis cylinder.

from scpf import (
    BOTTOM, FRONT, LEFT, RIGHT,
    Axis, Box, Cylinder, Sphere,
)

plate = Box(80, 50, 8)
board = Box(80, 50, 12).at(
    0, 0, 0,
    anchor=FRONT + BOTTOM,
).fillet(
    4,
    edges=[BOTTOM + LEFT, BOTTOM + RIGHT],
)
pin = Cylinder(d=8, h=20, axis=Axis.Z).at(
    10, 10, 8,
    anchor=BOTTOM,
)
side_pin = Cylinder(d=8, h=20, axis=Axis.X).at(-10, 0, 0)
ball = Sphere(12)

body = Sphere(20) & Box(30, 30, 30)
centered_bore = Cylinder(d=8, h=30, axis=Axis.X).at(body)

at(x, y, z) places CENTER at those coordinates unless another anchor=... is supplied. Passing another Shape instead uses shape-relative CENTER-to-CENTER placement. Forge derives the native Box corner, Cylinder base or Sphere center from the selected datum; callers do not add manual half-size corrections.

Draw a 2D profile, then extrude it

A Rectangle2D is a planar profile rather than a 3D body. 2D geometry is authored inside an explicit Sketch scope. Polygon2D can be created on the XY, XZ or YZ plane.

from scpf import Sketch, Rectangle2D, Polygon2D

with Sketch(plane="XY") as plate_sketch:
    Rectangle2D(80, 50)
plate = plate_sketch.extrude(8)

with Sketch(plane="XZ") as side_sketch:
    Polygon2D(
        [(0, 0), (40, 0), (40, 8), (8, 8), (8, 30), (0, 30)],
        plane="XZ",
        world=True,
    )
side = side_sketch.extrude(10)

# Signed distance chooses the side of the sketch plane.
backward = plate_sketch.extrude(-8)
centered = plate_sketch.extrude(8, sym=True)

A sketch plane affects where its axes go; changing the camera does not rotate its geometry. Leave the with Sketch(...) scope, then call sketch.extrude(...) to create 3D material. A positive distance follows the sketch-plane normal, a negative distance goes the other way, and sym=True divides a positive distance equally over both sides. Direct Rectangle2D(...).extrude(...) syntax is intentionally not supported.

Select profiles when extruding a Sketch

By default Sketch.extrude() uses every closed profile in the Sketch. Use profiles=[(x, y), ...] when only some closed regions should be extruded or cut. The points are fixed coordinates in the Sketch itself; users do not need SolidCraft profile indices or curve ids.

from scpf import Anchor, Axis, Box, Circle2D, Depth, Sketch

board = Box(120, 80, 5, anchor=Anchor.BOTTOM)
with Sketch(name="Selected holes", on=board, parent=Anchor.TOP) as holes:
    seed = holes.add(Circle2D(d=8), offset=(-30, 0))
    holes.rectangular_pattern(
        seed,
        count=4,
        spacing=20,
        direction=Axis.X,
    )

board = board - holes.extrude(
    Depth.THROUGH_ALL,
    profiles=[(-30, 0), (-10, 0), (30, 0)],
    exact_regions=True,
)

SolidCraft 0.42 stores a successful point selection using the curves around the selected profile where possible. That lets the selection follow the profile when the saved design recomputes. exact_regions=True asks SolidCraft to use exactly the region containing each point. Profile points must be fixed finite numbers; Forge Parameters and expressions are not accepted in this field.

Repeat and mirror profiles inside one Sketch

Sketch.rectangular_pattern() makes a native SolidCraft sketch pattern from a profile that already belongs to the Sketch. Sketch.mirror() mirrors a profile, a pattern result or an earlier mirror result. Both methods return a Sketch result that can be passed to another supported Sketch operation.

from scpf import Anchor, Axis, Box, Circle2D, Depth, Sketch

board = Box(200, 120, 8)
with Sketch(name="Dog holes", on=board, parent=Anchor.TOP) as holes:
    seed = holes.add(Circle2D(d=8), offset=(-40, 20))
    row = holes.rectangular_pattern(
        seed,
        count=4,
        spacing=25,
        direction=Axis.X,
    )
    holes.mirror(row, axis=Axis.X)

board = board - holes.extrude(Depth.THROUGH_ALL)

The same operations work with native Slot profiles. A pattern or mirror result can be used as the source of the next operation.

from scpf import Anchor, Axis, Sketch, SlotCenterToCenter2D

with Sketch(name="Clamp slots", on=board, parent=Anchor.TOP) as slots:
    seed = SlotCenterToCenter2D((20, 20), (40, 20), 8)
    arm = slots.rectangular_pattern(
        seed,
        count=2,
        spacing=50,
        direction=Axis.X,
    )
    opposite = slots.mirror(arm, axis=Axis.Y)
    slots.mirror(arm, axis=Axis.X)
    slots.mirror(opposite, axis=Axis.X)

count, count2, spacing and spacing2 may use suitable model Parameters, so those values remain editable in the saved SolidCraft design. Current native qualification covers attached Sketch(on=...) use. Pattern directions support Axis.X, Axis.Y or a fixed 2D vector. Mirrors currently support the Sketch X or Y origin axis. Per-instance pattern suppression is not supported.

SolidCraft 0.42 stores the curves selected when a mirror is created. If a pattern later creates extra curves after its count changes, those new curves are not added to that existing mirror automatically.

Add, subtract and intersect

body = Box(50, 50, 20)
tool = Cylinder(d=12, h=22).at(0, 0, 0)
joined = body + tool       # union, where supported
cut = body - tool          # difference, where supported
shared = body & tool       # intersection, where supported

The supported compiler path depends on the operands. Native feature history and CSG trees are not interchangeable for every operation. For manufacturing features such as holes, prefer the native feature operations.

API on this page

These values and signatures are generated from the current Python API. They are shown here so the normal guide flow does not require opening the reference for every detail.

Axis

Select one of the native principal X, Y or Z axes.

Axis.X · Axis.Y · Axis.Z

Use when: Use Axis for primitive orientation and supported patterns, for example Cylinder(..., axis=Axis.X) or a linear Hole pattern along Axis.Y.

Current limits: Axis is a principal-axis selector, not an attachment reference and not an extrusion Direction.

Shape.at()

Place a shape at absolute coordinates or align it to another Shape.

Shape.at(self, x=0, y=0, z=0, *, anchor=<Anchor.CENTER: 'center'>, child=<Anchor.CENTER: 'center'>)

Use when: Use shape.at(x, y, z) for geometric placement. Box, Cylinder, Cone and Sphere support their documented anchors. Use shape.at(target) for the supported shape-to-shape CENTER alignment.

Current limits: Shape-to-shape alignment currently supports CENTER-to-CENTER only. at() is geometric placement/alignment; selecting a support face for a feature is the job of Shape.on().

Sketch

Create an explicit named 2D sketch scope.

Sketch(*, name='Profile', on=None, parent=<Anchor.TOP: 'top'>, plane=None, origin=None, offset=None)

Use when: Author one or more 2D profiles before creating a 3D extrusion. A Sketch may be standalone on XY/XZ/YZ or supported by an existing Shape.

Current limits: Sketch(on=target) selects the body modified by the later extrusion. With the default parent=Anchor.TOP, Forge selects the largest +Z planar face at replay time. An explicit plane/origin bypasses face lookup. BOTTOM/CENTER relative placement still requires supported base metadata. offset remains a standalone-plane option. Leave the with-scope before extruding.

Sketch.add()

Add and place a supported 2D profile in this Sketch.

Sketch.add(self, profile, *, anchor=None, offset=(0, 0))

Use when: Add a profile explicitly or apply a deliberate sketch-local offset. Dimension-defined profiles default to semantic CENTER. Polygon2D, Text2D and native Slot profiles keep their authored coordinates.

Current limits: Explicit Anchor.CENTER is supported for Circle2D, Rectangle2D and RoundedRectangle2D. Polygon2D, Text2D and native Slot profiles define their own sketch-local coordinates; leave anchor=None for those profile types.

Sketch.rectangular_pattern()

Repeat a profile or earlier Sketch result with a native rectangular pattern.

Sketch.rectangular_pattern(self, source, *, count, spacing, direction=<Axis.X: 'X'>, count2=1, spacing2=None, direction2=None, alignment='right', alignment2='right', reversed=False, reversed2=False)

Use when: Repeat one Circle, Slot or other supported profile without drawing every copy separately. The returned Sketch result represents the source plus its copies and may be passed to mirror() or another supported Sketch operation.

Current limits: The operation must be authored inside the active Sketch. Current native qualification covers attached Sketch(on=...) use. The two counts may create at most 500 instances in total. Per-instance suppression is not supported. SolidCraft 0.42 stores the curves selected by a mirror when that mirror is created. If a pattern later creates extra curves after its count changes, those new curves are not added to that existing mirror automatically.

Sketch.mirror()

Mirror a profile or earlier Sketch result over the sketch X or Y axis.

Sketch.mirror(self, source, *, axis)

Use when: Create symmetric sketch geometry from a Circle, Slot, pattern result or earlier mirror result. The returned Sketch result contains the mirrored copies and may be used by a later supported Sketch operation.

Current limits: The operation must be authored inside the active Sketch. Current native qualification covers attached Sketch(on=...) use. Only the sketch X and Y origin axes are supported. SolidCraft 0.42 stores the curves selected when the mirror is created. If an upstream pattern later creates extra curves after its count changes, those new curves are not added to that existing mirror automatically.

Sketch.sheet_metal()

Create a native sheet-metal body from this closed flat Sketch.

Sketch.sheet_metal(self, *, thickness, bend_radius, k_factor=0.5, rule_name='Forge Sheet')

Use when: Start a fabricated sheet part from its flat blank before applying holes, folds, hems or other sheet-metal features.

Current limits: The first qualified form requires one standalone XY Sketch with one closed profile. Leave the Sketch scope before creating the sheet.

Sketch.extrude()

Extrude selected profiles from a completed Sketch.

Sketch.extrude(self, distance, *, sym=False, profiles=None, exact_regions=False)

Use when: Leave the Sketch context and create or cut material normal to the sketch plane. Use profiles= when the Sketch contains more closed regions than the extrusion should use.

Current limits: A standalone Sketch requires a finite non-zero distance. Depth.THROUGH_ALL is only meaningful for a Sketch attached to an existing Shape and cannot be combined with sym=True. Profile pick points must be fixed finite numbers; Parameters and expressions are not accepted because SolidCraft 0.42 profile points are numeric.

Create a native rectangular solid around a declared anchor datum.

Use when: Model a simple rectangular part directly without introducing a Sketch.

Current limits: The default anchor is CENTER, so an unplaced Box is centred around the model origin in X, Y and Z. Use anchor=BOTTOM for a box whose bottom face centre is at Z=0. Use at() for later placement.

SlotCenterToCenter2D

Create a straight Slot from the centres of its two round ends.

Current limits: p0 and p1 must be different points. The straight part runs between these two end centres.

SlotOverall2D
